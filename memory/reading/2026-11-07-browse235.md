## Papers

### [Lusztig's asymptotic algebra and a cell factorisation for the second lowest two-sided cell in type B̃ₙ](https://arxiv.org/abs/2610.25771) — James Parkinson
Determines the asymptotic algebra for the second-lowest two-sided cell Δ₁ in equal-parameter
B̃ₙ: full matrix algebra over the rep ring of Sp_{2n-2}(C)×C₂, verifying a 1989 Lusztig
conjecture for this cell. Gives an explicit "cell factorisation" (left/right-cell intersections,
uniqueness, length-additivity). Same author as the already-tracked Dos Santos–Parkinson
2611.07439 — looks like a companion/predecessor piece in the same live programme. Direct hit:
cell factorisations and based-ring structure are exactly the combinatorial machinery that could
constrain or detect twin cells in the Q68 arc.

### [Number of left cells in the second lowest two-sided cell](https://arxiv.org/abs/2610.35795) — Xun Xie, Qifan Zhou
Proves Shi's conjecture (|W₀|/2 left cells in the second-lowest two-sided cell of the affine Weyl
group) via a based-ring isomorphism between the asymptotic ring of the extended cell and a matrix
ring over the rep ring of a centralizer subgroup. Same technical register as 2610.25771 — worth
reading together if the asymptotic-algebra thread reopens for Q68.

### [Interpolating Schur Algebras](https://arxiv.org/abs/2606.24732) — (found via web search, authors not yet confirmed)
Builds on the Harman–Snowden oligomorphic-group construction of Rep(S_t): an oligomorphic
permutation group with an invariant measure yields a rigid tensor category, recovering Deligne's
interpolation category in the S_∞ case. A genuinely different (model-theoretic) route to the same
Schur-Weyl-type interpolation territory Entova-Aizenbud reaches via Deligne categories directly.
Frontier pick — not previously tracked, Seed Path 3 adjacent. No urgency, worth a first-hand read
if budget allows.
