# Q39 — (LS) locator for §11 of proofs/2026-10-25-crownF-strict-reciprocity.md (2026-10-25)

## What §11 actually uses
- Only the **count**: for λ = jω_m (type C_m, P = P_m, X_κ ⊂ LG(m,2m)),
  dim H^0(X_κ, O(j)) = #{LS paths π of shape jω_m with initial direction τ_1 ≤ κ in W/W_λ}.
  This is the λ → jω_m instance of the Demazure-type character formula for a single dominant weight; no
  standard-monomial / chains-of-paths / concatenation statement is needed. Degree j is handled by taking λ = jω_m
  directly (the formula is for arbitrary dominant λ), so no "degree-n piece of the coordinate ring" SMT form is required.
- Weight multisets (char) are used only in the computer check (lspaths.py vs dem.py), not in the proof.
- Non-simply-laced type C is needed. Littelmann's theorem holds for every symmetrizable Kac–Moody algebra, so type C_m is covered.

## Mismatch with §11
- **Main point:** Littelmann proves an identity between LS paths and the *Demazure-operator* expression
  Λ_{a1}∘⋯∘Λ_{ar}(e^λ). Turning this into char V_w(λ) or into h^0(X_w, L_λ) needs the geometric Demazure character
  formula (Demazure; Joseph 1985; Andersen 1985; Ramanathan 1985; Kumar 1987; Mathieu 1988). §11's (LS) bullet writes
  "char V_w(λ) = Σ…" as if Littelmann proved it. The fix is to state (LS) as the operator identity and put
  "char H^0(X_w, L_λ)^* = Λ_w(e^λ)" into (G1′), which already cites that package. This is a citation-hygiene issue. It
  does not leave a mathematical gap.
- Bruhat convention: Littelmann's condition is τ_1 ≤ τ in W/W_λ, with τ_1 the initial direction. This matches §11
  (τ_1 ≤ κ).
- Duality: X_w = closure(BwP/P) with H^0(X_w, L_λ)^* = V_w(λ) = U(b)v_{wλ}. §11's d(μ) = #{α > 0 : ⟨μ, α^∨⟩ < 0} is
  ℓ of the minimal coset representative with wλ = μ, so the conventions are consistent. Counts are insensitive to the
  dual.
- No SMT form is needed. Lakshmibai–Littelmann–Magyar and JAMS 11 (1998) are not required.

## Side finding: a novelty risk for the Ehrhart viewpoint
Mathieu, Bourbaki 798 §4, p. 220–221, reports Dehy's result: X(w) = {u ≤ w} carries a simplicial structure with an
integral structure P_w(n), and LS paths satisfy P_w(nλ) ≅ P_w(n). "Cela permet d'interpréter les dimensions des modules
de Demazure comme des polynômes d'Ehrhart." Mathieu adds that he does not know whether P_w can always be realised as a
lattice polytope. The reference is R. Dehy, *Combinatorial results on Demazure modules*, J. Algebra 205 (1998) 505–524.
- What this pre-empts: the "Demazure dim = Ehrhart-type count" frame.
- What it does not pre-empt, as far as can be seen: the LG order-polytope/Λ model and reciprocity.
- Next step: read Dehy 1998 (already flagged in §11.5 as the nearest unread candidate). Its priority goes up.

## Suggested citation sentence
"By Littelmann's path form of the Demazure character formula [Littelmann, Invent. Math. 116 (1994), §5.2; see also
Proc. ICM 1994, p. 305], for every dominant λ and w ∈ W/W_λ one has Λ_{w}(e^λ) = Σ e^{π(1)}, the sum running over LS paths π
of shape λ with initial direction ≤ w. Combined with the Demazure character formula
char H^0(X_w, L_λ)^* = Λ_w(e^λ) (Andersen, Ramanathan, Kumar, Mathieu), this gives h^0(X_w, L_λ) = #{such π}. We apply it
with λ = jω_m."
