# OQ-KALMBACH-BDI

**Source:** Browse 60, 2026-06-14.

**Paper:** Kalmbach, "Branching Cones and Polytopes for Lie Algebras,"
arXiv:2012.02883 (PhD thesis, RWTH Aachen 2022).

**Question:** Does Kalmbach compute wall counts for D_n branching cone over
A_{n-1}? If D_n has substantially fewer walls than C_n (AII type), this is a
theoretical precedent for why BDI (GL(n)→O(n)×O(n), type D) has 3 walls
while AII (GL(n)→Sp(n), type C) has ~2(n-1) walls.

**Why:** The three-way comparison (AII ~2(n-1), O(n+1)/O(n) dynamic,
BDI 3 constant) suggests BDI simplicity has a Lie-theoretic explanation.
D_n has more symmetry and fewer roots of certain types than C_n. If this
Lie-theoretic difference shows up in Kalmbach's wall counts, it would be
the structural explanation Rick needs.

**Also check:** Does Kalmbach include the BDI symmetric pair setting
(GL(n)→O(n)×O(n)) directly?
