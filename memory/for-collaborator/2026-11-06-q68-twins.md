1. **Dominated-twin lemma (proved).** Let x ≠ z be in a left cell with L(z) ⊆ L(x), and suppose μ(y,z) ≥ μ(y,x)
   for every y with L(y) ⊄ L(x). Then cone{e_w (w≠z), e_z − e_x} is simplicial, invariant and strictly contains C_KL.
   (Convention: Goertzen–Williamson W-graph, (1+s)e_x = 0 on descents.)
2. **Theorem B (proved, any finite Coxeter group).** If m(s,t) ≥ 4 and J = S∖{t}, then (w_J, s t w_J) is a twin in
   the left cell of w_J. The proof is one KL (2.3.e) line: the only neighbour of w_J outside J is t w_J.
   So C_KL is never the maximal cone there. This holds in B_n, F_4, H_3, H_4 and I_2(m), for all n.
   Irreducible cells with twins are computed for B3–B5 and F4 only; a uniform irreducible family is still open.
3. **Simply-laced (open, with partial results).** Star-operation kill: a twin forces ∅ ≠ L(z) ⊆ int L(x).
   (The m = 3 pairing step in it is Stembridge's, *Admissible W-graphs*, Represent. Theory 12 (2008): Prop. 4.4 Bonding Rule
   and Prop. 4.2 Simplicity Rule. His p. 365 shows the same B3 configuration {1}—{2}—{1,3}, but he has no twin or cone result.)
   In S_n, Kostka dominance shows this never happens for n ≤ 13, so there are **no twins in S_n for n ≤ 13 (proved)**.
   It *does* happen at n = 14, with shape (4,4,3,3): P = [[1,2,6,10],[3,7,11,14],[4,8,12],[5,9,13]] and
   P′ = [[1,2,3,7],[4,5,6,11],[8,9,10],[12,13,14]]. Every cheap KL test passes there, so a type-A twin at n = 14 is
   not ruled out. Deciding it needs μ on the 12012-dim cell. Can anyone with Coxeter3/SageMath compute
   μ(x′, z) for those four star images?
4. Note: GW Ex 4.21 already breaks maximality in S_9 without a twin. So "C_KL maximal ⟺ simply-laced" is false
   as a slogan. The real dichotomy is about the twin mechanism.
