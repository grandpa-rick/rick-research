# Q68: "(ii)-elements always kill" — half proved, rest reduced; a layer toolkit decides 5 of the 7 open S_16 pairs (PROVE 282, 2026-11-07)

Full write-up: `proofs/2026-11-07-q68-ii-kills.md`. Status: UNSENT. Wake decides whether this goes into a short Q68 update.

**The question.** Take a candidate pair (x, z): same left cell, L(x) = A, ∅ ≠ L(z) ⊆ int A. Let y be in the cell with L(y) ⊋ A and μ(y, x) ≠ 0. Is μ(y, z) = 0?

**Proved.**
1. **Parity-failing pairs.** If l(x) ≢ l(z), the answer is yes, by parity alone.
2. **Parity-OK pairs reduce to an x-free statement**, Lemma I: N[L(z)] ⊆ L(x) ⇒ μ(x, z) = 0.
3. **A parabolic "layer" toolkit for S_n.** It rests on the elementary identity P_{v′u,vu} = P_{v′,v}, for u a minimal coset representative. Three consequences:
   - (D) If n sits in the same row of T and T′, then μ_λ(T, T′) = μ_{λ−□}(T∖n, T′∖n).
   - (K) If the letters reverse-bumped out of T and T′ at some corner c satisfy ρ_T(c) < ρ_{T′}(c), and μ ≠ 0 would force T < T′ in every cell, then μ = 0.
   - (R) If those letters are equal, reduce to λ − c.
4. **Census update.** The tools decide all 5 UNDECIDED (5,5,3,3) pairs of the S_16 census as NO, by certificates replayed with independent code. The census is now 112 twin / 296 no / 2 undecided.

**Open, and where it is stuck.** Lemma I itself. Three routes died:
- The rank-2 W-graph relations are tautological on such nested edges.
- No canonical cell witnesses Bruhat incomparability.
- Layer methods are blind on "primitive" pairs: comparable in every cell, with no Young layer ever coinciding.

The two remaining (6,4,3,3) pairs are of this kind, with gaps 19 and 23 in S_16. A proof needs a global invariant that sees N[L(z)] ⊆ L(x), for example a sign-projection estimate for W_{N[L(z)]}. Lemma I has no small-rank test at all: it is vacuous below n = 14 in type A, and in D_4, D_5. At n = 16, 26 parity-failing pairs are undecided by every method so far. No decided case is nonzero, but a counterexample, if one exists, would sit among those primitive pairs.
