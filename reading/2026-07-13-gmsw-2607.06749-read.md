## 1. What GMSW proves

**Theorem 1.1 (GMSW).** Let m, n, d ∈ ℕ with m ≤ n, d. The SL_2(F)-plethysm Δ^{(n,m)} Sym^d E has a filtration

    L_{m-1}  ⊃  L_{m-2}  ⊃  ...  ⊃  L_1  ⊃  0

whose k-th layer (for k = 1, ..., m) equals

    L_{k} = Sym_{n+m} Sym^{d-k} E ⊗ Δ^{(n-k, m-k)} Sym^k E.

Field-independent. First multi-layer such isomorphism (Hermite, Wronskian, MW25 were all single-layer).

**The Sym-function identity being categorified** (their (1.2)):

    s_{(n,m)} ∘ s_d(q, q⁻¹) = Σ_{k=1..m} [d+n+m-k choose n+m]_q · s_{(n-k, m-k)} ∘ s_k(q, q⁻¹)

At q=1: dim S^{(n,m)}(d+1-dim) = Σ_k C(d+n+m-k, n+m) · dim S^{(n-k, m-k)}(k+1-dim).

**Proof machinery.** Section 2.8 "Weyl modules as vector spaces of polynomials." For the one-row case they realise Sym^n Sym^d E ≅ Λ_{≤d}[x_n] (symmetric polys in n vars, degree ≤ d each). For two-row (n,m) the Weyl module is
     Δ^{(n,m)} Sym^d E ⊂ Λ_{≤d}[x_{11},...,x_{1n}] ⊗ Λ_{≤d}[x_{21},...,x_{2m}]
via the element ∏_{i=1..m}(1 − (x_{1i}, x_{2i})) applied to symmetric f⊗g.

Two maps do the work: π̃ (Section 3.1) — an injection Sym_{M+N} Sym^b E ⊗ Δ^λ Sym^a E ↪ Sym_N Sym^b E ⊗ Δ^λ Sym^{a+b} E (when N ≥ a), and φ (Section 3.2) — a surjection Sym_{(n,m)} Sym^k E ↠ Sym_{(ñ,i)} Sym^k E built from the "flip" combinatorics of Fischer-Gangl-Gutiérrez-Kumari (FGGK26, in prep). Their composition realises each layer as a subquotient.

## 2. Structural parameters — GMSW vs Rick

**GMSW:** partition (n, m) with **≤ 2 rows** (outer Weyl-functor shape); inner SL_2 rep is Sym^d E; running index k ∈ [1, m]. Total four running parameters (n, m, d, k) — but the k index is the FILTRATION index, and the Weyl functor shape (n, m) is fixed at 2 rows.

**Rick's M_j:** partition λ = (a, b, c) with **3 rows** (S_n irrep V_λ label); running index j (number of e_2 factors); n = a+b+c is total size. Four independent parameters (a, b, c, j).

The parametric ranges are:
- GMSW: (n, m, d, k) with n ≥ m ≥ 1, d ≥ m, 1 ≤ k ≤ m.
- Rick: (a, b, c, j) with a ≥ b ≥ c ≥ 0, 0 ≤ j ≤ n/2.

## 3. Attempted identifications

### 3.1 Direct partition match (n, m) ↔ (a, b)

Set GMSW's outer partition (n, m) = (a, b), c=0 (Rick's 2-row slice). GMSW's k index runs 1..m = 1..b. Rick's j runs 0..n/2.

Rick's M_j at c=0 (2-row) with j=1:
    M_1(a, b, 0) = f^{(a,b)} · P_1(a, b, 0) / n(n-1) = f^{(a,b)} · (a+1)b / n(n-1)

GMSW's k=1 layer multiplicity: q=1 gives C(d+a+b-1, a+b) · dim S^{(a-1, b-1)}(2-dim) = C(d+a+b-1, a+b) · (a-b+1).

These do not equal each other for any natural (d, k, j) alignment. Test: a=b=2:
- M_1(2, 2, 0) = 2 · 3·2 / (4·3) = 1.
- GMSW at (n=2, m=2, d, k=1): [d+3 choose 4]_q · dim S^{(1,1)}(2-dim). dim S^{(1,1)}(2) = 1. So layer size = C(d+3, 4) polynomial in d. For d=1: C(4, 4) = 1 = M_1(2,2,0). Coincidence? Try a=3, b=1, j=1:
- M_1(3, 1, 0) = ⟨s_{(3,1)}, e_2 p_1^2⟩ = f^{(3,1)} · P_1(3,1,0) / (4·3) = 3 · (4·1) / 12 = 1.
- GMSW at (n=3, m=1, d=1, k=1): [3+1+1-1 choose 4]_q · dim S^{(2,0)}(2-dim) = C(4, 4) · 3 = 3. **Mismatch.**

Direct partition match FAILS.

### 3.2 (n, m) ↔ (j, j) with d varying (categorify e_2^j)

Set GMSW (n, m) = (j, j). Then Δ^{(j,j)} Sym^d E has filtration with k = 1, ..., j layers, and the LHS character is s_{(j,j)} ∘ s_d.

Test j=1: Δ^{(1,1)} Sym^d E = Λ^2 Sym^d E. Character s_{(1,1)}[d+1]_q = ((d+1)² − (d+1))/2·… no wait let's just take dims. dim = C(d+1, 2). At d=1: dim = 1.

Rick's M_1 depends on λ, so needs a specific λ. If we take λ = (j, j) = (1, 1): M_1((1,1)) = ⟨s_{(1,1)}, e_2⟩ = 1. Matches. But this is just Λ^2 E = e_2 dim 1, trivially self-consistent.

Try j=2, (n,m)=(2,2). Λ^{(2,2)} Sym^d E has k∈{1,2} layers. Say d=2:
- k=1 layer: Sym^4 Sym^1 E ⊗ Δ^{(1,1)} Sym^1 E = Sym^4 E ⊗ Λ^2 E ≅ Sym^4 E (det=1 on SL_2). dim 5.
- k=2 layer: Sym^4 Sym^0 E ⊗ Δ^{(0,0)} Sym^2 E = 1 ⊗ 1 = 1.
- Total dim Δ^{(2,2)} Sym^2 E = 6. Check: Weyl dim of S^{(2,2)}(3-dim) = 6 ✓ (by hook-content).

Now Rick's M_2(λ) for arbitrary λ ⊢ n with j=2. Try λ = (2,2) (n=4): M_2((2,2)) = ⟨s_{(2,2)}, e_2² · 1⟩ = ⟨s_{(2,2)}, e_2²⟩. e_2² = s_{(2,2)} + s_{(2,1,1)} + s_{(1,1,1,1)}. So M_2((2,2)) = 1.

GMSW filtration layer values 5 and 1 don't have any obvious relation to Rick's M_2((2,2)) = 1.

The (n,m)=(j,j) identification is not delivering M_j either.

### 3.3 (n, m, d) ↔ some combination of (a, b, c, j)

Rick has 4 independent parameters, GMSW has 4 (n, m, d, k). Setting up a linear map with meaningful match: any injection (a,b,c,j) → (n,m,d,k) must satisfy m ≤ n ≤ ? and k ≤ m. Any such assignment forces at least one of Rick's parameters to be constrained. But c-uniformity means "c is free"; if c gets mapped to k or fixed, we lose the very structure we want.

Even ignoring parameter-count, the **character structure mismatch is fundamental**:
- GMSW layer character: polynomial q-binomial · S^(2-row) character on 2 vars ⇒ polynomial in d and (n,m).
- Rick's M_j: sum over Kostka-Motzkin-weighted skew SYT counts ⇒ involves f^{λ/μ} hook-length ratios.

These are structurally different generating classes.

### 3.4 Sym-function level: is e_2^j p_1^{n-2j} a plethysm s_μ ∘ s_ν?

No.
- e_2^j = Σ_μ K_{μ',(2^j)} s_μ — a Schur-linear-combination, not a single Schur.
- p_1^{n-2j} = h_1^{n-2j} = Σ_ν f^ν s_ν.
- Their product is a Sym-function PRODUCT, categorified by direct tensor product of modules.
- s_{(n,m)} ∘ s_d in GMSW is a plethystic COMPOSITION, categorified by Δ^{(n,m)} applied to Sym^d E as a functor of an SL_2 rep.

**Product ≠ Composition** — this is exactly the failure mode Rick diagnosed for Routes I-IV. GMSW does NOT escape it; it categorifies compositions.

## 4. The "symmetric functions model for Weyl modules" (§2.8) — does it help?

GMSW's polynomial model:
    Sym^n Sym^d E ≅ Λ_{≤d}[x_n]     (symmetric polys in n vars, each ≤ deg d)

Basis: {s_λ(x_n) : λ ∈ L(n, d)} = partitions in n × d box.

This is a Sym-function realisation of a specific plethystic module — but the polynomials live in n commuting variables (not the ∞-var Λ where Rick's e_2^j p_1^{n-2j} lives). And the module is Sym^n Sym^d E specifically — Rick's operand is a PRODUCT e_2^j · p_1^{n-2j}, not any single Weyl functor image.

The extension to Δ^{(n,m)} Sym^d E (§2.9, Weyl-modules-as-quotients, and §3 with π̃ and φ) uses 2-row combinatorics via the FGGK26 "flip" of partitions in an L(k,k) box. **Zero mention of 3-row Weyl functors, and zero mention of anything that decomposes as Σ K_{μ',(2^j)} f^{λ/μ}.**
