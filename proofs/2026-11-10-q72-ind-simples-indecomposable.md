# Q72(i): Ind of two 0-Hecke simples is indecomposable unless both are projective

PROVE 289, 2026-11-10. Status: **proved** (all N). Check script: `proofs/prove289/check.py`. It verifies every intermediate claim below for N ≤ 8 (769 cases, 0 mismatches).

## Conventions
- H_N = H_N(0) is generated by π_1,…,π_{N−1} with π_i² = π_i plus the braid relations. For w ∈ S_N, π_w := π_{i_1}⋯π_{i_ℓ} for any reduced word.
- For D ⊆ [N−1], C_D is the 1-dim module with π_i ↦ [i ∈ D]. These are all the simples (Norton). A composition I ⊨ m is identified with its descent set D_I ⊆ [m−1].
- **Fact N (Norton 1979).** dim P_D = #{w ∈ S_m : Des(w) = D}. Hence C_D is projective iff D ∈ {∅, [m−1]}, i.e. I ∈ {(m), (1^m)}. "Projective" below always means this.
- Fix I ⊨ a and J ⊨ b with a, b ≥ 1, N = a+b. Let B := H_a ⊗ H_b ⊆ H_N (the generators π_i, i ≠ a). Let V = C_I ⊠ C_J = k·v, and put χ(i) := [i ∈ D] for D := D_I ∪ (a + D_J).
- M = M_{I,J} := H_N ⊗_B V, with g := 1⊗v.

## Theorem
M_{I,J} is indecomposable unless I and J are both projective. In the both-projective case, M_{I,J} ≅ P_{I·J} ⊕ P_{I⊙J}, with two nonzero summands.

## 0. Word model
- H_N is free as a right B-module on {T_w = π_w : w ∈ W^{(a,b)}}, the minimal left coset representatives (shuffles). So M has basis e_w = T_w ⊗ v.
- Encode a shuffle w by the word x(w) ∈ {A,B}^N indexed by *values*: x_j = A iff w^{-1}(j) ≤ a.
- For the action of π_i, look at (x_i, x_{i+1}):
  - **AB** (i ascent, s_i w a shuffle): π_i e_w = e_{s_i w}, whose letters at i, i+1 are BA.
  - **BA** (i a left descent of w): π_i T_w = π_i π_i T_{s_i w} = T_w, so the vector is fixed.
  - **AA or BB** (ascent, s_i w = w s_p with p ≠ a by Deodhar's lemma): π_i e_w = T_w π_p ⊗ v = χ(p) e_w.
    - p is the rank of i among the A-values, for AA,
    - or a + (rank of i among the B-values), for BB.
- The same model, with its own parameters, describes any Ind_{H_c⊗H_d}^{H_{c+d}}(C_{D'} ⊠ C_{D''}).

## 1. End(M) and the locality criterion
**Step 1 (Frobenius).** φ ↦ φ(g) is a linear isomorphism End_{H_N}(M) → E := {u ∈ M : π_i u = χ(i)u for all i ≠ a}. Write φ_u for the inverse image of u.

**Step 2 (top).** Hom_{H_N}(M, C_Z) ≅ Hom_B(V, Res C_Z). This has dimension 1 if Z ∖ {a} = D, and 0 otherwise.
- So top M = C_{Z_1} ⊕ C_{Z_2}, where Z_1 = D and Z_2 = D ∪ {a}. These are C_{I⊙J} and C_{I·J}.
- Let f_j : M → C_{Z_j} be the unique maps with f_j(g) = 1. Since π_w acts on C_Z by ∏[letters ∈ Z],
  f_j(e_w) = [w ∈ W_{Z_j}]   (support of a reduced word).

**Step 3 (criterion).** Each φ ∈ End M induces diag(c_1, c_2) on top M = C_{Z_1} ⊕ C_{Z_2}, with c_j = f_j(φ(g)). This gives an algebra map ρ : End M → k × k.
- ker ρ = {φ : φ(M) ⊆ rad M}. Every such φ is nilpotent, because φ(rad^j M) = rad^j φ(M) ⊆ rad^{j+1} M. So ker ρ ⊆ J(End M).
- im ρ is a subalgebra of k×k containing (1,1), so it is either k·(1,1) or all of k×k.
- Therefore End M is local iff im ρ = k·(1,1). That gives:

> **(Crit)** M is indecomposable ⟺ f_1(u) = f_2(u) for every u ∈ E.

## 2. Computing f_1, f_2
- **f_1.** W_{Z_1} ⊆ W_a × W_b and the shuffles meet it only in id. So f_1(u) = u_id.
- **f_2.** Let [α, β] ∋ a be the component of Z_2 containing a. Explicitly α = a − r' and β = a + s', where:
  - r' = #{a−1, a−2, … consecutively in D_I};
  - s' = #{1, 2, … consecutively in D_J}.
- A shuffle lies in W_{Z_2} iff it lies in W_{[α,β]}. Reason: a shuffle has no right descent inside W_a×W_b, so its factors in the other components of Z_2 are trivial.
- A shuffle w fixes every value j < α iff [1, α−1] ⊆ A-values. It fixes every value j > β+1 iff all A-values are ≤ β+1. Hence

  f_2(e_w) = [x_1 = … = x_{α−1} = A] · [x_{β+2} = … = x_N = B].   (2.1)

  (Check script: f_1 and f_2 are module maps to C_{Z_1} and C_{Z_2}, all cases N ≤ 8.)

## 3. Mackey factorisation of E
- Let k(w) := #{B-letters among x_1..x_a}, for 0 ≤ k ≤ min(a,b). The generators π_i with i ≠ a preserve k(w), so Res_B M = ⊕_k M_k.
- **k = 0.** M_0 = k·g.
- **k ≥ 1.** Cut the word as x = (x_1..x_a | x_{a+1}..x_N). The map e_w ↦ (left word) ⊗ (right word) is a B-isomorphism M_k ≅ L_k ⊗ R_k, where:
  - L_k := Ind_{H_{a−k}⊗H_k}^{H_a}(C_{I^{(1)}} ⊠ C_{J^{(1)}}), with D_{I^{(1)}} = D_I ∩ [1, a−k−1] and D_{J^{(1)}} = D_J ∩ [1, k−1];
  - R_k := Ind_{H_k⊗H_{b−k}}^{H_b}(C_{I^{(2)}} ⊠ C_{J^{(2)}}), with D_{I^{(2)}} = {p−(a−k) : p ∈ D_I, p > a−k} and D_{J^{(2)}} = {q−k : q ∈ D_J, q > k}.
- Proof of the isomorphism: compare the §0 rules. All left values are below all right values, so the A-rank of a left letter is its rank inside the left word. A right A-letter has overall rank (a−k) + its rank inside the right word, and a right B-letter has overall rank k + its rank inside the right word. The eigenvalues χ therefore match the descent sets listed.
- Degenerate cases: L_a = C_{J^{(1)}} (word B^a) and R_b = C_{I^{(2)}} (word A^b).
- Joint eigenspaces of commuting families acting on the two tensor factors multiply. So
  E ∩ M_k = U_k ⊗ U'_k, where U_k = {x ∈ L_k : π_i x = [i∈D_I] x} ≅ Hom(C_I, L_k) and U'_k ≅ Hom(C_J, R_k).
- By (2.1), f_2|_{M_k} = λ_k ⊗ λ'_k, where λ_k(x) = [x_1..x_{α−1} = A] and λ'_k(y) = [y_{β+2−a}.. = B].
- f_2|_{M_k} is a B-map to C_I ⊠ C_J. So if both λ_k and λ'_k are nonzero, each one is a module map: λ_k : L_k → C_I and λ'_k : R_k → C_J.

**Consequence.** f_1 = f_2 on M_0. For k ≥ 1, f_1 vanishes on M_k. Combining with (Crit):

> M decomposable ⟹ ∃ k ≥ 1 with λ_k(U_k) ≠ 0 and λ'_k(U'_k) ≠ 0.

Fix such a k. Then λ_k ≠ 0 and λ'_k ≠ 0, so both are module maps. An x ∈ U_k with λ_k(x) ≠ 0 gives a nonzero composite C_I → L_k → C_I, so **C_I is a direct summand of L_k**. In the same way, **C_J is a direct summand of R_k**. Also, λ_k ≠ 0 forces k ≤ r' + 1, since the left free region [α, a] has only r'+1 slots.

## 4. Induction on N
The base case N = 2 is a = b = 1, where both simples are projective. Assume the theorem holds below N, suppose M_{I,J} is decomposable, and take k as in §3.

**Lemma.** If 1 ≤ k ≤ a−1 and C_I is a summand of L_k, then I is projective. The same holds on the right: if 1 ≤ k ≤ b−1 and C_J is a summand of R_k, then J is projective.

*Proof.* L_k = M_{I^{(1)}, J^{(1)}} lives at size a < N, so the induction hypothesis applies. If L_k is indecomposable, then L_k ≅ C_I, so dim L_k = C(a,k) = 1. That is impossible for 1 ≤ k ≤ a−1. Otherwise L_k is projective, and C_I, as a summand of a projective, is projective. ∎

Cases:
- **k < a and k < b.** The Lemma applies on both sides, so I and J are projective.
- **k = a < b.** J is projective by the Lemma. C_I | L_a = C_{J^{(1)}} gives D_I = D_J ∩ [1, a−1], which is ∅ or [a−1]. So I is projective.
- **k = b < a.** Symmetric: I is projective, and D_J = D_{I^{(2)}} is ∅ or [b−1].
- **k = a = b.** Here D_I = D_J. Also λ_a ≠ 0 forces a ≤ r'+1, so [1, a−1] ⊆ D_I. Hence I = J = (1^a), which is projective.

So decomposable ⟹ both projective.

**Converse.** If I and J are projective, then C_I = P_I and C_J = P_J. M = Ind(P_I ⊠ P_J) is projective, since H_N is B-free. Its multiplicity of P_Z equals dim Hom(M, C_Z), which is 1 exactly for Z ∈ {Z_1, Z_2} by Step 2. So M ≅ P_{I·J} ⊕ P_{I⊙J}. ∎

## Remarks
- The proof is just Frobenius applied twice: once to End, once to the top. Mackey then reduces the gluing question to "does C_I split off a smaller induced module L_k?", and induction answers that. (Cold-read NIT fixed 2026-11-11: the Mackey decomposition Res_B M = ⊕_k M_k is the standard double-coset decomposition and is a direct sum at EVERY q; q=0 is not what makes it direct. What q=0 supplies is the specific shape of the pieces: the 0-Hecke word-model rules of §0 identify M_k ≅ L_k ⊗ R_k, a tensor product of smaller induced 0-Hecke modules of the same type with matched eigenvalues.)
- The constraint k ≤ r'+1 is used only in the k = a = b case. It is what excludes, e.g., I = J = (2,2) (dim End = 4 but indecomposable).
- **Negative control (step 4 of the route).** In the both-projective case the witness k exists. For example, k = 1 with a, b ≥ 2 has L_1, R_1 projective and containing C_I, C_J. The hypothesis that fails in the non-projective case is "C_I is a summand of L_k". The wake's guess ("I has both an ascent and a descent") is the k < a shadow of this condition, via Fact N.
- Hypotheses used: q = 0 (for the shape of the Mackey pieces M_k ≅ L_k ⊗ R_k with the 0-Hecke action, §3, for the 1-dim simples C_D, and for Norton's Fact N — NOT for directness of Mackey, which holds at all q), the 2-block parabolic, and 1-dim modules. Q72(ii), describing End in general, is untouched. The proof does describe the rad-part: End M = k ⊕ ker ρ.
