# Q46 — principal specialisation does NOT separate the Demazure characters (PROVE 262, 2026-10-28)

**Answer: NO.** The first failure is κ=(3,1) (any m ≥ 3). The exact rank is |κ|+1 for every κ. That is the same rank as at x=1,
and the π_q kernel specialises at q=1 to the Crown K kernel. One theorem (q-Lemma D, sharp) covers every regular grading.

## Setup
LG(m,2m). Weights are in coordinates (μ_1..μ_m). Simple roots: α_i = e_i − e_{i+1} (i<m), α_m = 2e_m. ω = ω_m = (1,…,1).
ch_κ(j) = D_{w_κ} e^{jω} is computed as in `scripts/prove249d/dem.py`. Here D_i f = (f − e^{−α_i} s_i f)/(1 − e^{−α_i}).
This is exactly what `Di` computes: for k = ⟨μ,α_i^∨⟩ ≥ 0 it returns e^μ + … + e^{μ−kα_i}.
For strict ρ ⊆ {1..m}, ε_ρ := w_ρ ω is the sign vector with −1 at positions m+1−k for k ∈ ρ (the script's `target`).

ρ_C = (m, m−1, …, 1) is ρ for C_m in these coordinates: half-sum of e_i±e_j (i<j) and 2e_i gives (m,…,1). ✓
So π_q (x_i ↦ q^{m+1−i}) is x^μ ↦ q^{(μ,ρ_C)}, matching PROVE.md. More generally, for a ∈ Z^m let π_a : x_i ↦ q^{a_i}.
Call a *regular* if (β,a) ≠ 0 for every root β (a_i ≠ 0 and a_i ≠ ±a_j).

Standard facts used (W^P for LG, P = maximal parabolic of ω_m):
(F1) the minimal coset representatives v ≤ w_κ in W^P are exactly the w_ρ with ρ ⊆ κ (shifted diagrams), and ℓ(w_ρ) = |ρ|.
(F2) For v ∈ W^P and u ∈ W: u ≥ v whenever u ∈ vW_P. Also, if u ∈ w_κW_P and u ≤ w_κ, then u = w_κ (length).

## Theorem (q-Lemma D, sharp form)
Let a be regular and κ strict. Over Q(q),

  rank { j ↦ π_a ch_ρ(j) : ρ ⊆ κ } = #{ (ε_ρ, a) : ρ ⊆ κ }  ("number of bins").

In particular the family is independent iff ρ ↦ (ε_ρ,a) is injective on {ρ ⊆ κ}.

### Corollary (Q46)
(ε_ρ, ρ_C) = Σ_k ±k = m(m+1)/2 − 2|ρ|, so the bins of π_q are the sizes |ρ|. Every size 0..|κ| occurs, because a maximal
chain of shifted diagrams from ∅ to κ adds one box at a time. Hence

  rank_{Q(q)} {π_q ch_ρ : ρ ⊆ κ} = |κ| + 1,   kernel dimension  d(κ) = #{ρ ⊆ κ} − |κ| − 1 = Σ_n (N_n(κ) − 1),

where N_n(κ) = #{strict ρ ⊆ κ : |ρ| = n}. The family is independent iff [∅,κ] is a chain, iff κ = (k) or κ = (2,1).
To see this: two rows with κ_1 ≥ 3 give κ ⊇ (3,1) ⊋ (3), (2,1), two incomparable diagrams of size 3.
**The smallest failure is κ = (3,1)**, with d = 1 (sizes 3: (3), (2,1)). The principally specialised recursion
ch_κ(j+1) = Σ c_{κρ} ch_ρ(j) does not determine π_q(c_{κρ}): its solution set is an affine space of dimension d(κ).

### Convention warning: which "principal" specialisation
PROVE.md's π_q uses ρ_C = (m,…,1). It gives e_m height 1, α_i height 1 (i<m), and α_m = 2e_m height 2. So every box weight
β(x) has height 1, and this is exactly the "height" grading in the long draft's Lemma `lem:indep`. Kac's principal
specialisation e^{−α_i} ↦ q is a different grading: ρ^∨ = (m−½,…,½). Use a = 2ρ^∨ = (2m−1,…,3,1), which is regular, so the
Theorem applies: (ε_ρ, 2ρ^∨) = m² − 2(2|ρ| − ℓ(ρ)). The bins are therefore 2|ρ| − ℓ(ρ), and that separates (3) [5] from (2,1) [4].
Collisions need equal 2n−ℓ inside one interval. The smallest is (4,1) ~ (3,2), contained in **κ = (4,2) (m ≥ 4)**. Next comes
(5) ~ (3,2,1) inside (5,2,1). So under Kac's specialisation the answer is still NO, but the first failure moves to (4,2)
(|κ| = 6). At m = 3 every κ is separated. The rank is #{2|ρ| − ℓ(ρ) : ρ ⊆ κ}.

## Proof of the Theorem
**Step 1: algebraic localisation.** In the twisted group algebra Q(x)#W, D_i = (1−e^{−α_i})^{−1}(1 − e^{−α_i} s_i).
Take the reduced word w_κ = s_{i_1}⋯s_{i_ℓ} and expand the product D_{i_1}⋯D_{i_ℓ}:

  D_{w_κ} = Σ_{u} R_u(x) u,

where u runs over the products of subwords. So every u with R_u ≠ 0 satisfies u ≤ w_κ (subword property).
Every factor is a Laurent monomial divided by products of (1 − e^{−γ}), γ a root, because conjugating e^{−α} by W gives e^{−γ}.
Only the full word gives u = w_κ (the word is reduced). Its coefficient is

  R_{w_κ} = Π_{k=1}^{ℓ} ( −e^{−β_k} / (1 − e^{−β_k}) ),  β_k = s_{i_1}⋯s_{i_{k−1}} α_{i_k}  (roots),

which is a nonzero element of Q(x). Apply this to e^{jω} (u·e^λ = e^{uλ}) and group u by cosets uW_P, so that uω = vω:

  ch_κ(j) = Σ_{v ∈ W^P} A_{κ,v}(x) e^{j vω},  A_{κ,v} = Σ_{u ∈ vW_P, u ≤ w_κ} R_u.

By (F2), A_{κ,v} ≠ 0 only if v ≤ w_κ, and A_{κ,w_κ} = R_{w_κ}. This is an identity in Q(x), valid for every integer j.

**Step 2: specialise.** a is regular, so no denominator 1 − e^{−γ} vanishes under π_a (π_a(1 − e^{−γ}) = 1 − q^{−(γ,a)}).
So the A's specialise, and π_a R_{w_κ} ≠ 0. Then π_a e^{jvω} = t_v^j with t_v = q^{(vω,a)}. With v = w_ρ,

  π_a ch_κ(j) = Σ_{ρ ⊆ κ} a_{κρ}(q) t_ρ^j,  a_{κρ} := π_a A_{κ,w_ρ},  a_{κκ} ≠ 0,  t_ρ = q^{(ε_ρ,a)}.

**Step 3: upper bound.** Every π_a ch_ρ (ρ ⊆ κ) lies in span{ j ↦ t^j : t ∈ {t_ρ : ρ ⊆ κ} }. The functions j ↦ t^j for
distinct t ∈ Q(q)^× are linearly independent over Q(q) (Vandermonde on any #bins consecutive j). So the span has dimension
#bins, and rank ≤ #bins.

**Step 4: lower bound.** For each bin s (a value of (ε_ρ,a)), pick ρ(s) of *minimal size* among the ρ ⊆ κ in that bin, and
order the bins by |ρ(s)|. Take the coefficient of t_s^j in π_a ch_{ρ(s)}. It is Σ a_{ρ(s),σ} over σ ⊆ ρ(s) in bin s.
Any σ ≠ ρ(s) in that sum has |σ| < |ρ(s)|, which contradicts minimality. So the coefficient is a_{ρ(s)ρ(s)} ≠ 0.
For any other bin s' that π_a ch_{ρ(s)} touches, the touching σ satisfies σ ⊊ ρ(s), so |ρ(s')| ≤ |σ| < |ρ(s)|.
So the #bins × #bins matrix [coefficient of t_{s'}^j in π_a ch_{ρ(s)}] is triangular in this order with nonzero diagonal,
and rank ≥ #bins. ∎

Sanity check: Lemma D (over Q(x)) is the case "a generic". Then all ε_ρ are distinct (they are distinct sign vectors), every
bin is a singleton, and Step 4 is the old top-term/Vandermonde argument run from the top vertex.

## The kernel is the x=1 (Crown K) kernel, lifted
x=1 is the non-regular grading a = 0, so the Theorem does not apply there. Separate argument: ch_ρ(j)|_{x=1} = χ(X_ρ, O(j)) is a
polynomial in j of degree exactly dim X_ρ = |ρ| (Snapper; O(1) is ample on X_ρ). So the rank at x=1 is |κ|+1 as well: the upper bound
is polynomials of degree ≤ |κ|, and the lower bound comes from one ρ per size. **Same rank, same d(κ).**

Limit claim: let K(q) ⊆ Q(q)^{R} be the π_q kernel (dim d) and K_1 ⊆ Q^R the x=1 kernel (dim d). Then K(q)|_{q=1} = K_1.
Proof: let J = {0,…,2^m}. The evaluation matrix M(q) = [π_q ch_ρ(j)]_{j∈J} has Laurent entries. It computes the function rank both
for generic q (|J| ≥ #bins) and at q=1 (|J| ≥ |κ|+1). Saturate K(q) ∩ Z_{(q−1)}[q]^R. That is free of rank d, and its reduction mod
(q−1) is a d-dimensional space inside ker M(1) = K_1 (M(q)v(q) = 0 ⇒ M(1)v(1) = 0). Equal dimensions give equality. ∎

Explicitly at κ=(3,1), m=3 (computed, `q46_kernel.py`), the π_q kernel is spanned by

  ch_{(2,1)} − (q²−q+1)/(q²+1) · ch_{(3)} − q/((q+1)(q²+1)) · ch_{(2)} − q²/((q+1)(q²+1)) · ch_{(1)},

and at q=1 this is ch_{(2,1)} − ½ ch_{(3)} − ¼ ch_{(2)} − ¼ ch_{(1)}, which is exactly the x=1 kernel (Crown K). ✓

**Reading (Crown M).** One q does not see more than x=1 does. π_q grades by size, x=1 grades by j-degree, and both gradings
are |ρ|. The extra information lives in the directions of the grading space that separate the bins: the full torus, or any regular
a off the collision hyperplanes (ε_ρ − ε_σ, a) = 0. For pairs with |ρ Δ σ| ≥ 3 these are *not* root hyperplanes. ρ_C sits on
b_3 = b_1 + b_2 (b_k := a_{m+1−k}), the (3)/(2,1) wall. So "uniqueness lives upstairs" is confirmed: it needs a grading that
separates (3) from (2,1).

**Bad locus (step 2c of PROVE.md), exact answer.** Among regular a, the family {π_a ch_ρ : ρ ⊆ κ} is dependent iff a lies on one of
the hyperplanes Σ_{k ∈ ρ∖σ} b_k = Σ_{k ∈ σ∖ρ} b_k, where ρ ≠ σ ⊆ κ.
