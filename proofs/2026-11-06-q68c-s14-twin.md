# Q68(c) at S_14 — a dominated twin in type A (PROVE 280, 2026-11-06)

Scripts and outputs are in `proofs/prove280/`. Background, conventions, Lemma A, (F1)–(F3), C1–C4 and Theorem C3 are in
`proofs/2026-11-06-q68-kl-cone-twins.md`.

## Problem

Use GW convention C (arXiv 2604.18894, Ex. 4.7). W = S_14, left cells are {Q fixed}, and L(w) = Des P(w), where P is the
insertion tableau of the one-line word (so left multiplication by s_i swaps the values i and i+1).
Put λ = (4,4,3,3) and

    P  = [[1,2,6,10],[3,7,11,14],[4,8,12],[5,9,13]]    Des P  = {2,3,4,6,7,8,10,11,12}
    P' = [[1,2,3,7],[4,5,6,11],[8,9,10],[12,13,14]]    Des P' = {3,7,11} = int Des P.

**Question.** Is (x, z) = ((P,Q), (P',Q)) a dominated twin?

## Answer: YES

**Theorem T14.** Fix the left cell Γ of S_14 with Q = [[1,2,3,4],[5,6,7,14],[8,9,10],[11,12,13]].
Put x = (P,Q) = [5,9,13,14,4,8,12,3,7,11,1,2,6,10] (length 55) and z = (P',Q) (length 67).
Then (x, z) is a dominated twin in Γ. By Lemma A, the KL cone C_KL of this left cell (a model of the Specht module
S^{(4,4,3,3)}) is **not** a maximal {1+s}-invariant pointed cone. A simplicial invariant cone strictly containing it is
cone({e_w : w ≠ z} ∪ {e_z − e_x}).

The same holds for the other three (★)-violators at n = 14 (Theorem T14' below). Together with Theorem C3
(no twins for n ≤ 13), this shows that **14 is the least n for which S_n has a dominated twin**, and it gives the full
list of twin pairs (by P-tableaux) in S_14.

So the simply-laced hunch (Q68-simply-laced-conj: "no twins in simply-laced W") is **FALSE**, already in type A.

## Proof

### Step 1. Lemma S (star invariance, m = 3). Proved here.

This is KL79 Theorem 4.2. KL79 is recall-only (no copy on disk), so here is a proof that uses only the KL recursion and
(F1). Let s, t ∈ S with m(s,t) = 3. Every w ∈ D_L(s,t) can be written uniquely in exactly one of four *forms*, where u is
minimal in its left ⟨s,t⟩-coset (so L(u) ∩ {s,t} = ∅):

| form | type (L ∩ {s,t}) | *w | direction |
|---|---|---|---|
| su  | {s} | tsu | up (by t) |
| tsu | {t} | su  | down (by t) |
| tu  | {t} | stu | up (by s) |
| stu | {s} | tu  | down (by s) |

Write μ̃(a,b) for the symmetric μ: it is μ(a,b) if a < b, μ(b,a) if b < a, and 0 otherwise.
The KL facts used:

- (2.2.c) If tv > v, then
  P_{x,tv} = q^{1−c} P_{tx,v} + q^c P_{x,v} − Σ_{z<v, tz<z} μ(z,v) q^{(l(tv)−l(z))/2} P_{x,z}, where c = 1 if tx < x and c = 0 otherwise.
- (2.3.g) If t ∈ L(w), then P_{x,w} = P_{tx,w}.
- (F1), as in the main file.

The recursion is the one implemented in `prove280/klperm.py`. That implementation reproduces
P_{1324,3412} = P_{2143,4231} = P_{e,4231} = 1+q.

**Lemma S.** For all y, w ∈ D_L(s,t), μ̃(y,w) = μ̃(*y,*w).

*Proof.* If u = u′ (same coset), check the six pairs directly. The edges su–tsu, tu–stu, su–stu and tsu–tu have μ = 1,
and * permutes them. The pairs su–tu and tsu–stu have equal lengths, so μ̃ = 0 on both. Assume u ≠ u′ from now on.

*Different types.* Suppose y has type {s} and w has type {t}. The Claim in C1 (from (F1)) shows that μ̃(y,w) ≠ 0 forces
w = *y. In that case μ̃(*y,*w) = μ̃(w,y). If instead μ̃(*y,*w) ≠ 0, the same Claim gives *w = **y = y, so w = *y.
Either way the two sides agree.

*Same type, same form (S-i).* We prove μ̃(su,su′) = μ̃(tsu,tsu′). The other three same-form cases follow by swapping s
and t, or by reading the identity from right to left. By symmetry assume l(u) < l(u′), and let d = l(u′) − l(u). If d is
even, both sides vanish by parity. Let w = su′. Then tw = tsu′ > w. Apply (2.2.c) with v = w and x = tsu (so c = 1 and
tx = su):

  P_{tsu,tsu′} = P_{su,su′} + q P_{tsu,su′} − Σ_{z<su′, t∈L(z)} μ(z,su′) q^{(l(su′)+1−l(z))/2} P_{tsu,z}.

Take the coefficient of q^{(d−1)/2}, which is the μ-coefficient for the gap d.
- The first term gives μ(su,su′).
- Second term. By (2.3.g) with s ∈ L(su′), P_{tsu,su′} = P_{stsu,su′}, and the gap is d − 2. So for d ≥ 3 the needed
  coefficient is the top one, namely μ(stsu,su′) if stsu < su′ and 0 otherwise. For d = 1 it is 0.
- Third term. If s ∉ L(z), then (F1) gives z = s·su′ = u′, but t ∉ L(u′). So s, t ∈ L(z). The coefficient needed is the
  top (μ-)coefficient of P_{tsu,z}. Since s ∈ L(z) \ L(tsu), (F1) forces z = stsu. That z has P_{tsu,z} = 1 and the
  exponent works out to 0. So this term contributes μ(stsu,su′) when stsu < su′. That needs d ≥ 3, because
  l(stsu) = l(su′) + 2 − d.

The second and third terms cancel, so μ(tsu,tsu′) = μ(su,su′).

*Same type, mixed form (S-ii): the gap-changing case.* We prove μ̃(su,stu′) = μ̃(tsu,tu′). The type-{t} version
μ̃(tu,tsu′) = μ̃(stu,su′) follows by swapping s and t. Let δ = l(u′) − l(u), so l(stu′) − l(su) = δ + 1 and
l(tu′) − l(tsu) = δ − 1. If δ is odd, both sides are 0. First assume δ ≥ 0. Apply (2.2.c) to stu′ = s·tu′, with v = tu′
and x = su (so c = 1 and sx = u):

  P_{su,stu′} = P_{u,tu′} + q P_{su,tu′} − Σ_{z<tu′, s∈L(z)} μ(z,tu′) q^{(l(u′)+2−l(z))/2} P_{su,z}.

Take the coefficient of q^{δ/2}, which is the μ-coefficient for the gap δ + 1.
- First term. By (2.3.g), P_{u,tu′} = P_{tu,tu′}. Its gap is δ, so its degree is at most (δ−1)/2 < δ/2, and the term
  gives 0. (When δ = 0, tu ≠ tu′, so P_{tu,tu′} = 0 anyway.)
- Second term. By (2.3.g) with t ∈ L(tu′), P_{su,tu′} = P_{tsu,tu′}. Its coefficient at q^{(δ−2)/2} is the
  μ-coefficient for the gap δ − 1, namely μ(tsu,tu′). This is 0 when δ = 0.
- Third term. If t ∉ L(z), then (F1) gives z = u′, but s ∉ L(u′). So s, t ∈ L(z). Parity makes the needed coefficient
  the top one, μ(su,z). Since t ∈ L(z) \ L(su), (F1) forces z = tsu, but s ∉ L(tsu). So this term is 0.

Hence μ(su,stu′) = μ(tsu,tu′) for δ ≥ 2. For δ = 0 the computation gives μ(su,stu′) = 0. Applying the s↔t mirror of the
same computation to the pair (tu′, tsu) gives μ(tu′,tsu) = 0 as well, so both sides vanish.
If δ < 0, run the s↔t mirror on (*w,*y) = (tu′,tsu) with δ′ = −δ > 0. ∎

*Machine control.* `test_star.py` checks μ̃(y,w) = μ̃(*y,*w) for all y, w ∈ D_L(s_i,s_{i+1}), all i, against full KL in
S_5 and S_6: 19200 + 921600 pairs, 0 violations (`out_star_invariance_S5S6.txt`).
`samedir.py` confirms that the S-ii (gap-changing) steps really are needed: same-form steps preserve the length gap, and
every certificate path below uses 5–9 mixed steps.

### Step 2. Which y must be checked.

Lemma A asks for μ(y,z) ≥ μ(y,x) for every y ∈ Γ with L(y) ⊄ L(x). Only y with μ(y,x) ≠ 0 matter, because μ ≥ 0.
Let A = L(x) = {2,3,4,6,7,8,10,11,12}.
- If y > x, pick r ∈ L(y) \ A. Then (F1) gives y = r x.
- If y < x and A ⊄ L(y), pick s ∈ A \ L(y). Then (F1) gives y = s x.
- If y < x and A ⊊ L(y), then Des P(y) ⊋ A. This is impossible in shape (4,4,3,3): Des ⊇ {2,3,4} forces 2, 3, 4, 5 into
  rows 1, 2, 3, 4, and likewise for 6–9 and 10–13. Then a descent at 1, 5, 9 or 13 would need a fifth row. The
  enumeration of all 12012 SYT agrees (0 found; `verify.py`).

So the y to check are exactly the y = s x ∈ Γ with L(y) ⊄ A, and each has μ(y,x) = 1 (length gap 1, comparable).
For this Q they are s ∈ {2, 5, 9, 12}, the four star images x′ of C4.

### Step 3. μ(x′_i, z) = 1 for each of the four, by explicit certificates.

For each x′_i, apply the simultaneous star operations *_j = * w.r.t. {s_j, s_{j+1}} to the pair (x′_i, z), along the
listed path. Each step requires both entries to lie in D_L(s_j,s_{j+1}). By Lemma S, μ̃ is constant along the path. The
endpoint is a Bruhat-comparable pair with length gap 1, so μ̃ = 1 there.

| s | path (j's) | end lengths |
|---|---|---|
| 2  | 2,4,2,6,8,6,4,7,6,10,8 | 59, 60 |
| 5  | 3,6,8,10,12,10,8,7,5 | 59, 60 |
| 9  | 7,5,3,1,3,4,6,10,8 | 59, 60 |
| 12 | 11,9,7,5,3,5,6,8,6,5,11 | 61, 62 |

`verify.py` replays each certificate independently: its own RSK, its own star map (asserting membership in D_L at every
step), and Bruhat order via the rank-matrix criterion, which is not the tableau criterion used for the search.
All four pass (`out_verify.txt`). No step has the pair in a single ⟨s,t⟩-coset, although Lemma S covers that case anyway.

### Step 4. Conclusion.

x ≠ z and L(z) = {3,7,11} ⊆ L(x). For every y ∈ Γ with L(y) ⊄ L(x), either μ(y,x) = 0 ≤ μ(y,z), or y = x′_i and
μ(y,z) = 1 = μ(y,x). Lemma A applies. ∎

## Theorem T14' (all of S_14)

The (★)-violating pairs (λ, A = L(x)) at n = 14 are exactly four (`list14.py`, exhaustive with Kostka dominance):

| λ | A = Des P_x | int A | P_x | P_z |
|---|---|---|---|---|
| (4,4,3,3) | {2,3,4,6,7,8,10,11,12} | {3,7,11} | [[1,2,6,10],[3,7,11,14],[4,8,12],[5,9,13]] | [[1,2,3,7],[4,5,6,11],[8,9,10],[12,13,14]] |
| (5,3,3,3) | same | {3,7,11} | [[1,2,6,10,14],[3,7,11],[4,8,12],[5,9,13]] | [[1,2,3,7,11],[4,5,6],[8,9,10],[12,13,14]] |
| (4,4,4,2) | {1,2,4,5,6,8,9,10,12,13} | {1,5,9,13} | [[1,4,8,12],[2,5,9,13],[3,6,10,14],[7,11]] | [[1,3,4,5],[2,7,8,9],[6,11,12,13],[10,14]] |
| (4,4,4,1,1) | same | {1,5,9,13} | [[1,4,8,12],[2,5,9,13],[3,6,10,14],[7],[11]] | [[1,3,4,5],[2,7,8,9],[6,11,12,13],[10],[14]] |

Each shape has exactly one SYT with Des = A and exactly one with ∅ ≠ Des ⊆ int A (`twin14.py`). Each pair is a dominated
twin. The certificates are in `certs_{1..4}.json` (Q = superstandard tableau for 2–4) and were replayed by `verify.py`.
For the last two shapes there are 3 boundary y's each (s = 3, 7, 11). No SYT has Des ⊋ A in any of the four shapes.
The second pair of shapes are the conjugates of the first. Since L-inclusion is reversed under w ↦ w w₀, these are new
pairs, not formal images.

By C2 (proved), every twin in S_14 is one of these four (P_x, P_z) pairs.

**Q-independence (computed).** `allcells.py` runs the same decision in every left cell of each shape
(see `out_allcells_*.txt`), and a sample of 40 random Q for (4,4,3,3) also gives YES. A proof for every cell would come
from right star operations (Lemma S applied to inverses, P_{x,w} = P_{x⁻¹,w⁻¹}) together with dual-equivalence
connectivity of SYT(λ). The connectivity is recall-only, so that is not graded here. One cell is all the theorem needs.

## Verification and controls

- `control_s6.py`: the orbit-search decision procedure (star orbit plus parity, Bruhat and F1 kills) against full KL in
  S_5 and S_6, over all pairs within left cells. It reproduces all 120 + 1118 μ = 1 pairs and all 118 + 2550 μ = 0 pairs,
  with 0 wrong and 0 undecided. Shape-invariance holds there with 0 violations. This is the separator: the procedure
  outputs both verdicts, and both match.
- `gap_min.py`: across all 12012 Q, the minimal gaps l(z) − l(x′_i) are (11,11,13,13). Direct interval KL was out of
  reach, which is why the star lever was used.

## What this changes

- Q68-simply-laced-conj (hunch) is **refuted**: type A has dominated twins, first at n = 14.
- C3's "no twins n ≤ 13" is sharp.
- GW-type consequence: C_KL is not maximal for the Specht modules S^λ with λ ∈ {(4,4,3,3), (5,3,3,3), (4,4,4,2),
  (4,4,4,1,1)}, and each comes with an explicit simplicial witness. GW Ex. 4.21 (S_9, (4,4,1)) is a different
  mechanism (non-twin, as C3 shows).
- The mechanism of the twin is the gap-changing (mixed-form) star step. Same-form steps preserve the gap
  (`samedir.py`: no same-form path exists), and every certificate needs 5–9 mixed steps to bring the gap from 11–13
  down to 1.
