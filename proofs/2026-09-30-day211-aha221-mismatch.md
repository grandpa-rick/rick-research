# Day 211 — aha_221 "MISMATCH" diagnosed: CONVENTION/NUMERIC BUG, (TC) unaffected

**Verdict: CONVENTION BUG in the test harness (float exponents). (TC) is unaffected.**

## What day210/aha_221.py computes
- Direct side: day196 `compute_e_star_product(m,[a,b,c])` applies t^{-C(a,2)}e_a(Y), then e_b(Y), then e_c(Y) to 1
  (Hikita level-1 action, pi uses q^{-1}X_1), i.e. e_c⋆(e_b⋆(e_a⋆1)) with e_a⋆1 = e_a. So "(2,2,1)" is the
  length-3 product e_1⋆(e_2⋆e_2) (an ℓ=3 *output* built from 207b + one (TC) step with k=1, a=b=2), not a new input shape.
- TC side: `elam((λ3,λ1,λ2))` = star(λ3, ek_er(λ1,λ2)): inner via 207b, outer via (TC) coefficients (`tc_extract.coeffs`), s→1/q.

## Root cause
day196 `compute_e_star_product` sets `scalar_factor *= t**(-f*(f-1)/2)` with Python ints, so `/2` gives a float:
t**(-1.0). The output then contains t**1.0, t**2.0, ... alongside t, t**2. `sympy.cancel` does not identify
t**2.0 with t**2, so every "difference" is of the shape Σ c_j (t^j − t^{j.0}) — spurious nonzeros.
Evidence (m=5, (2,2,1)): raw diff at (3,1,1) is (q t^{1.0} − q t − t^{1.0} + t)/q^4, etc.; after
`nsimplify(rational=True)` every coefficient difference is exactly 0.

## Confirmation
- `scripts/day211_mismatch/aha_221_fixed.py` (rationalize floats, otherwise identical): (2,2,1) m=5 MATCH;
  (3,2,1) m=6 MATCH (all e-basis coefficients).
- Independent engine (day205 flint AHA + day208 ekY, exact integer coefficients), `iso.py` m=5 and m=6:
  e_2⋆1 = e_2; e_2⋆e_2 = ek_er(2,2); e_1⋆(e_2⋆e_2) direct = elam(1,2,2) = star(1, direct e_2⋆e_2). All MATCH.
- Not a truncation artifact: m ≥ total degree in both runs; the e-basis expansion is unique there.

## Lessons
- Never compare sympy expressions containing Float exponents with `cancel`; use `sp.Rational(f*(f-1),2)` or `//2`.
- Day 196 DS results used the same engine; their zero/nonzero verdicts on individual coefficients could in
  principle be affected the same way (not re-audited here).
