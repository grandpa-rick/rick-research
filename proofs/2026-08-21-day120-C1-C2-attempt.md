## Part 1. Proof of (C2)

### Setup

Odd $j = 2l+1$, $d_{\max} = 3l+1$. Even-parity spine 3-part partitions: $\mu = (2l, l+1+r, l+1-r)$ for $r = 0, 1, \ldots, l-1$.

To prove:
$$A_{\text{even}}(l) := \sum_{r=0}^{l-1} (-1)^r K_{\mu', (2^{2l+1})} = (-1)^{l+1}.$$

### Lemma 1 (Weyl formula for K_even)

$$K_{\mu', (2^{2l+1})} = (2l+1)\left[\binom{2l}{l-r} - \binom{2l}{l-r-1}\right] - \left[\binom{2l+1}{l-r+1} - \binom{2l+1}{l-r-1}\right].$$

**Proof.** For a 3-part $\mu = (m_1, m_2, m_3)$ with $|\mu| = 2j$, we compute
$$K_{\mu', (2^j)} = \langle s_\mu, e_2^j \rangle = [x_1^{\rho_1} x_2^{\rho_2} x_3^{\rho_3}]\, e_2^j(x_1,x_2,x_3) \cdot \Delta(x_1,x_2,x_3),$$
where $\rho_i = m_i + 3 - i$ and $\Delta = \prod_{i<j}(x_i - x_j)$.

Expand:
$$e_2^j = \sum_{a+b+c=j} \binom{j}{a,b,c} (x_1x_2)^a (x_1x_3)^b (x_2x_3)^c = \sum \binom{j}{a,b,c} x_1^{a+b} x_2^{a+c} x_3^{b+c}.$$
$$\Delta = \sum_{\tau \in S_3} \mathrm{sgn}(\tau)\, x_1^{3-\tau(1)} x_2^{3-\tau(2)} x_3^{3-\tau(3)}.$$

For each $\tau \in S_3$, matching exponent gives $A_\tau = \rho_1 - (3-\tau(1))$, etc., and solving the linear system gives explicit $(a,b,c)$.

For the even-parity spine, $\rho = (2l+2, l+2+r, l+1-r)$. Computing the six terms of $\sum_\tau \mathrm{sgn}(\tau) M_\tau$ (where $M_\tau$ is the multinomial with the determined $(a,b,c)$), two terms have $c = -1$ (invalid) and vanish. The remaining four terms yield the stated formula, after using the identities $\binom{2l+1}{k, 2l+1-k-1, 1} = (2l+1)\binom{2l}{k}$ and $\binom{2l+1}{k, 2l+1-k, 0} = \binom{2l+1}{k}$.

**Verified numerically for $1 \le l \le 19$, all $r$; see `c2_weyl_formula.py`, `c2_closed_form.py`.**

### Lemma 2 (First binomial identity)

$$\sum_{r=0}^{l-1} (-1)^r \left[\binom{2l}{l-r} - \binom{2l}{l-r-1}\right] = (-1)^{l+1}.$$

**Proof.** Let $\mathrm{ballot}(n, k) := \binom{n}{k} - \binom{n}{k-1}$. Day 119 Identity A (even $j$ version):
$$\sum_{r=0}^{l} (-1)^r \mathrm{ballot}(2l, l-r) = 0.$$
The $r = l$ term is $(-1)^l \cdot \mathrm{ballot}(2l, 0) = (-1)^l \cdot 1$. Subtracting:
$$\sum_{r=0}^{l-1} (-1)^r \mathrm{ballot}(2l, l-r) = -(-1)^l = (-1)^{l+1}. \quad \blacksquare$$

### Lemma 3 (Second binomial identity)

$$\sum_{r=0}^{l-1} (-1)^r \left[-\binom{2l+1}{l-r+1} + \binom{2l+1}{l-r-1}\right] = (-1)^l \cdot 2l.$$

**Proof.** Substitute $k = l - r$ (so $r = 0, \ldots, l-1$ becomes $k = 1, \ldots, l$, with $(-1)^r = (-1)^{l-k}$):
$$T = (-1)^l \sum_{k=1}^{l} (-1)^k \left[\binom{2l+1}{k-1} - \binom{2l+1}{k+1}\right].$$

Split into two sums and re-index (let $j = k-1$ and $j = k+1$ respectively, using $(-1)^k = -(-1)^j$):
$$\sum_{k=1}^{l} (-1)^k \binom{2l+1}{k-1} = -\sum_{j=0}^{l-1} (-1)^j \binom{2l+1}{j},$$
$$\sum_{k=1}^{l} (-1)^k \binom{2l+1}{k+1} = -\sum_{j=2}^{l+1} (-1)^j \binom{2l+1}{j}.$$

Subtract: the middle terms $j = 2, \ldots, l-1$ cancel, leaving
$$-\binom{2l+1}{0} + \binom{2l+1}{1} + (-1)^l \binom{2l+1}{l} + (-1)^{l+1}\binom{2l+1}{l+1}.$$
Since $\binom{2l+1}{l} = \binom{2l+1}{l+1}$, the last two terms cancel:
$$= -1 + (2l+1) = 2l.$$

Therefore $T = (-1)^l \cdot 2l$. $\blacksquare$

### Combining

By Lemma 1,
$$A_{\text{even}}(l) = (2l+1) \sum_{r=0}^{l-1} (-1)^r \mathrm{ballot}(2l, l-r) + \sum_{r=0}^{l-1} (-1)^r \left[-\binom{2l+1}{l-r+1} + \binom{2l+1}{l-r-1}\right].$$

Applying Lemmas 2 and 3:
$$A_{\text{even}}(l) = (2l+1) \cdot (-1)^{l+1} + (-1)^l \cdot 2l = (-1)^{l+1} \left[(2l+1) - 2l\right] = (-1)^{l+1}. \quad \blacksquare$$

**Fully verified for $l = 1, \ldots, 19$ in `c2_proof_final.py`.**

## Part 2. Investigation of (C1)

### Setup

Odd-parity spine, $\mu^{(m)} = (2l+1, l+1+m, l-m)$, $m = 0, 1, \ldots, l$.
$\beta_m := $ constant term (i.e., $[s^0]$) of $\bar s^*_{\mu^{(m)}}(s)$, where
$$\bar s^*_\mu(s) := [t^{d_\mu}] s^*_\mu(u,y,c)\bigg|_{u=t,\ y+c=s,\ yc=t}.$$

Conjectured formula:
$$\beta_m = (-1)^{m+1}\left[(m+1)(2l+1) - \delta_{m,l}\right].$$

### Empirical verification

Using direct SymPy computation (`c1_symbolic_derive.py`), the formula has been verified for **all $(l, m)$ with $1 \le l \le 8$** — a total of $2 + 3 + 4 + 5 + 6 + 7 + 8 + 9 = 44$ cases including all $m \in \{0, \ldots, l\}$.

### Structural observations toward proof

1. **Setting $s = 0$ means $y + c = 0$, i.e., $c = -y$, and $yc = -y^2 = t$**, i.e., $y^2 = -t$. So
   $$\bar s^*_\mu(0) = [t^{d_\mu}] s^*_\mu(t, y, -y)\bigg|_{y^2 = -t}.$$

2. **Even-in-$y$ symmetry:** Under $y \to -y$, both $\det[(x_i)_{k_j}]$ and $V(u,y,c)$ pick up a factor of $-1$ (rows 2 and 3 swap). So $s^*_\mu(t, y, -y)$ is EVEN in $y$; write it as $P(t, y^2)$. Then $\bar s^*_\mu(0) = P(t, -t)$, and $\beta_m = [t^{d_\mu}] P(t, -t)$.

3. **Case split $m < l$ vs $m = l$:**
   - For $m < l$: $k_3 = l - m > 0$, so the Weyl determinant's column 3 has non-trivial falling factorials. Empirically, $P(t, y^2)$ has minimum $y$-degree $\ge 2$ (no constant-in-$y$ term). This eliminates the $\delta_{m,l}$ correction and yields $\beta_m = (-1)^{m+1}(m+1)(2l+1)$.
   - For $m = l$: $k_3 = 0$, so column 3 of the determinant is $(1, 1, 1)^T$. Expanding along column 3 gives an extra "vanishing" term contribution to $[y^0] P$; this produces the $-\delta_{m,l}$ correction.

4. **Bounding degrees:** Under the substitution $y^2 = -t$, contributions to $\beta_m$ come from monomials $t^a y^{2k}$ in $P$ with $a + k = d_\mu$. Direct computation shows a huge cancellation among these contributions; the surviving value follows a linear pattern in $m$ with an additive correction.

### KEY REFORMULATION (found today)

Using $\alpha_m = (-1)^m (m+1)$ (Day 118), the conjectured formula
$$\beta_m = (-1)^{m+1}\left[(m+1)(2l+1) - \delta_{m,l}\right]$$
is equivalent to the CLEAN identity
$$\boxed{\beta_m + j \cdot \alpha_m = (-1)^m \delta_{m,l}}$$
where $j = 2l+1$. Verified for all $l \le 7$, all $m$.

Interpretation: the "linearization" $L(s) := \alpha_m s + \beta_m$ of $\bar s^*_\mu(s)$ satisfies
$$L(-j) = -j \alpha_m + \beta_m = -2 j \alpha_m + (\text{extra}) = ?$$
Actually, since $L(-j) = -j \alpha_m + \beta_m$ and $\beta_m + j\alpha_m = (-1)^m \delta_{m,l}$, we have $L(-j) = -2j \alpha_m + (-1)^m \delta_{m,l}$. This is not immediately a "vanishing at a special point."

However, the identity $\beta_m + j \alpha_m = (-1)^m \delta_{m,l}$ has the flavor of the following statement: consider the coefficient extractor
$$\mathrm{Ext}[\phi](\mu) := [t^{d_\mu}] [\phi(s)] s^*_\mu(u=t, y+c=s, yc=t)$$
Then for $\phi(s) = 1 + j s$ (a degree-1 polynomial in $s$), we get $\mathrm{Ext}[1 + js](\mu^{(m)}) = \beta_m + j\alpha_m = (-1)^m \delta_{m,l}$.

The RHS $(-1)^m \delta_{m,l}$ = $(-1)^l$ at $m = l$, else 0. This has the flavor of a Kronecker delta arising from a boundary/degeneration case.

### What remains

Given time constraints, a full analytical proof of the identity $\beta_m + j\alpha_m = (-1)^m \delta_{m,l}$ was not completed. The empirical evidence (35+ verified $(l,m)$ pairs for $l \le 7$) is strong. Two viable paths forward:

1. **Direct approach:** The (u, sigma=0, pi) reduction (`c1_sigma_zero.py`) gives a clean polynomial $F(u, \pi)$ representing $s^*_\mu(u, y, -y)$ (in the pi = -y^2 variable). The identity should follow from a determinantal identity for $F(t, t)$, exploiting that $k_3 = 0$ at $m = l$ makes column 3 constant $= 1$ (yielding the delta correction).

2. **Molev-Sagan approach:** Use the shifted-Pieri formula (Molev-Sagan Thm 3.1) to expand $\bar s^*_\mu$ in factorial Schur functions, then extract low-order terms in $s$. This would give both $\alpha_m$ and $\beta_m$ (and higher orders) from a common formula.

**Status of (C1):** Empirically verified for $l \le 7$; identified as equivalent to the cleaner identity $\beta_m + j\alpha_m = (-1)^m \delta_{m,l}$; rigorous derivation not completed today.
