# Q71 — no (S_0, H_N(0))-bimodule filtration of 0-tensor space by L ⊠ M_I (PROVE 287, 2026-11-09/10)

Registry: `proofs/registry/seedQ1-qsym-quasicrystal.json`, nodes `Q71-*`. Check script: `proofs/prove287/chk.py`.

## Problem

V = C^n, n ≥ 2. Let H = H_N(0) act on the right of V^{⊗N} by Jung–Oh 2509.26194 (4.5) (π̄_i² = −π̄_i). On a word w = w_1…w_N with a = w_i, b = w_{i+1}:

  w·π̄_i = s_i w (swap) if a < b;  −w if a > b;  0 if a = b.

Let S_0 = End_H(V^{⊗N}). Here I write M_I for the indecomposable projective H-modules, I a composition with ℓ(I) ≤ n, and L_I for the simple S_0-modules.

**Theorem.** Let n ≥ 2. V^{⊗N} has a filtration by (S_0,H)-sub-bimodules with subquotients L_I ⊠ M_I (each admissible I once) **iff N ≤ 2**.

In fact the (⇒) direction proves something much stronger.

**Theorem′ (⇒, strong form).** Let n ≥ 2 and N ≥ 3. There is **no** chain of S_0-stable H-submodules 0 = X_0 ⊂ X_1 ⊂ … ⊂ X_m = V^{⊗N} in which every subquotient X_k/X_{k−1} is, as an H-module, isomorphic to P_k^{⊕d_k} for a single indecomposable projective P_k.

- The S_0-structure of the layers plays no role, so neither simplicity of L_I nor its character F_I is used.
- Labels, the Nakayama permutation and the case split n<N vs n≥N are not needed either.

A bimodule L ⊠ M_I is, as an H-module, M_I^{⊕dim L}. So Theorem′ ⇒ (⇒).

## Proof

**Lemma 1 (stable summands are Hom-orthogonal).** Let H be any finite-dimensional algebra, V a finite-dimensional right H-module and S = End_H(V). Let X ⊂ V be an S-stable H-submodule with V/X projective. Then V = X ⊕ Y for some H-submodule Y, and Hom_H(X, Y) = 0.

*Proof.* V/X is projective, so V → V/X splits, giving V = X ⊕ Y. Write p : V → X for the projection along Y; it is H-linear. Given f ∈ Hom_H(X,Y), set F = f∘p ∈ S. Then F(X) = f(X) ⊂ Y, and F(X) ⊂ X by S-stability. Hence f(X) ⊂ X ∩ Y = 0. ∎

Lemma 1 needs S to be the **full** commutant, because the projection p must lie in S. This is the only place that S_0 = End_H(V) is used.

**Lemma 2 (two hook summands).** Let N ≥ 3. Fix two letters 0 < 1 of V (possible since n ≥ 2).

- The words with one letter 1 and N−1 letters 0 are u_p (1 in position p). They span an H-stable weight space U.
- The words with one letter 0 and N−1 letters 1 are v_p (0 in position p). They span an H-stable weight space U′.

From the action:
- u_p π̄_{p−1} = u_{p−1}, u_p π̄_p = −u_p, and u_p π̄_i = 0 otherwise.
- v_p π̄_{p−1} = −v_p, v_p π̄_p = v_{p+1}, and v_p π̄_i = 0 otherwise.

(a) Set W = span{u_1,…,u_{N−1}}. Then U = C·(Σ_p u_p) ⊕ W as H-modules.
- W is stable because π̄ only moves the 1 leftward or scales.
- Σu_p is killed by every π̄_i: (Σu)π̄_i = u_i − u_i = 0.
- Σu ∉ W, and the dimensions add up.

Likewise U′ = C·(Σ v_p) ⊕ W′ with W′ = span{v_2,…,v_N}.

Every weight space is an H-direct summand of V^{⊗N}, since the action preserves letter content. So W and W′ are H-direct summands of V^{⊗N}.

(b) The map f : W → W′ with u_{N−1} ↦ v_N and u_k ↦ 0 for k < N−1 is a nonzero H-map. Check:
- span{u_1,…,u_{N−2}} is a submodule, so the kernel is stable.
- u_{N−1}π̄_{N−1} = −u_{N−1} and v_Nπ̄_{N−1} = −v_N.
- u_{N−1}π̄_{N−2} = u_{N−2} ↦ 0, and v_Nπ̄_{N−2} = 0 (letters 1,1).
- All other π̄_i kill both u_{N−1} and v_N.

(c) The map g : W′ → W with v_2 ↦ u_1 and v_p ↦ 0 for p ≥ 3 is a nonzero H-map. Check:
- span{v_3,…,v_N} is a submodule.
- v_2π̄_1 = −v_2 and u_1π̄_1 = −u_1.
- v_2π̄_2 = v_3 ↦ 0, and u_1π̄_2 = 0 (letters 0,0, since N ≥ 3).
- Other π̄_i kill both v_2 and u_1.

(d) W ≇ W′. The vector u_1 spans a submodule of W on which π̄_1 = −1 and π̄_i = 0 for i ≥ 2. Suppose y = Σ_{p≥2} c_p v_p ∈ W′ satisfies those relations.
- y π̄_1 = −c_2 v_2. Setting this equal to −y forces c_p = 0 for p ≥ 3.
- Then yπ̄_2 = c_2 v_3. Setting this equal to 0 forces c_2 = 0.

So W′ has no such submodule.

(e) W and W′ are local, hence indecomposable. W is cyclic, generated by u_{N−1}. Let R = span{u_1,…,u_{N−2}}, a submodule of codimension 1. Every proper submodule Z lies in R. To see this, take z = c·u_{N−1} + r ∈ Z with r ∈ R and c ≠ 0.
- u_kπ̄_{N−1} = 0 for k ≤ N−2 (positions N−1, N both carry 0), so z·(−π̄_{N−1}) = c·u_{N−1}.
- So u_{N−1} ∈ Z, hence Z = W.

So R is the unique maximal submodule, and W has simple top C_{{N−1}}. In particular W is indecomposable: if W = A ⊕ B then top W = top A ⊕ top B.

Same for W′: it is generated by v_2, and v_pπ̄_1 = 0 for p ≥ 3, so z·(−π̄_1) = c·v_2. Its unique maximal submodule is span{v_3,…,v_N}, with top C_{{1}}. This also gives (d) a second time, since the tops differ.

The machine check confirms dim End W = dim End W′ = 1 for N ≤ 6.

**Proof of Theorem′.** Suppose such a chain exists.
1. Each subquotient is projective. So each V/X_k has a filtration by projectives and is projective, and the chain splits as H-modules: V ≅ ⊕_k P_k^{⊕d_k}.
2. By Krull–Schmidt and Lemma 2(a),(e), W ≅ P_a and W′ ≅ P_b for some indices a, b. By (d), a ≠ b and the two iso types are different.
3. Let k be minimal with X_k containing a summand of type W or W′; say it is type W (the other case is symmetric, using g in place of f).
   - Then X_k ≅ ⊕_{j≤k} P_j^{d_j}.
   - None of P_1,…,P_{k−1} has type W or W′, and P_k is of type W, not W′.
   - So X_k has no summand of type W′.
4. Apply Lemma 1: V = X_k ⊕ Y. By Krull–Schmidt, the summand W′ of V lies (up to iso) in Y.
5. Then Hom_H(X_k, Y) ⊇ Hom_H(W, W′) ∋ f ≠ 0, which contradicts Lemma 1. ∎

**(⇐).** H_1(0) = C and H_2(0) = C[π̄]/(π̄²+π̄) ≅ C × C are semisimple. Then V = ⊕_D Hom_H(C_D, V) ⊠ C_D, and S_0 = ∏ End(Hom_H(C_D,V)). This is a direct sum of simple bimodules L ⊠ C_D = L ⊠ M_D. For n ≥ 2 both compositions of 2 occur, and the problem's labelling (char F_I) is the cited Jung–Oh Thm 4.13. ∎

## What this replaces / remarks

1. **The PROVE-file strategy is unnecessary.** That strategy was: socle obstruction, Nakayama ν = reversal, "only dim M_I = 1 end pieces", then the case split n<N / n≥N.
   - The real obstruction is a 2-cycle in the Hom-quiver of the summands present: W ⇄ W′. These are the hook projectives with tops at descent sets {N−1} and {1}.
   - Any S-stable filtration by isotypic projective layers needs an ordering of the summand types in which Hom only goes "backwards" (Lemma 1, iterated). A 2-cycle kills every ordering.
   - The general criterion (sketched, not needed): such a filtration exists ⟺ the summand types admit an order P_1,…,P_m with Hom(P_i, P_j) = 0 for i < j. With simple layers L ⊠ P one additionally needs End P = C.
   - For H_N(0) the Cartan matrix is symmetric (c_{IJ} = #{σ : Des σ = I, Des σ^{-1} = J}, σ ↔ σ^{-1}; this is KT folklore, not used above). So the criterion says the restricted Cartan matrix must be the identity. That fails as soon as N ≥ 3 and n ≥ 2.
2. **Negative control (generic q).** At generic q the same weight spaces give W ≅ W′ (both are the Specht module (N−1,1), which is simple). So step (d) fails and there is no contradiction, as it should be. The q=0 input is exactly that two *non-isomorphic* indecomposable projectives map nonzero both ways.
3. **Consistency with Wake 286 compute.** NO at (2,3), (3,3), (2,4), (3,4) and YES at (2,2) all agree. The computed "only dim-1 end pieces" pattern is a symptom: W and W′ can never be first among their pair.
4. **U_0 vs S_0 (caveat, not pursued).** Lemma 1 needs the projection to lie in the acting algebra. The PROVE file and question file say "(S_0,H), equivalently U_0 × H". That equivalence is **false** wherever ρ(U_0) ⊊ S_0, e.g. (2,3): 19 < 20, KT NCSF V Note 5.7. There U_0-stable submodules form a larger lattice, so the theorem above says nothing about U_0 × H filtrations. This is an open side question, recorded and not opened as a new Q here.
5. **Generality.** Theorem′ holds verbatim for any right H_N(0)-module V that contains summands of both types W and W′ (for example any V ⊇ both hook permutation modules), with S = End_H(V).
