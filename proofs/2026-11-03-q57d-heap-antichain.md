# Q57d + Q55a — Boolean ⇒ commuting cube on minuscule W^J, via Stembridge's heap theorem

PROVE 270 (written 2026-11-01, file dated 11-03 per plan). Status: **PROVED**, modulo first-hand-read citations to
Stembridge, *On the fully commutative elements of Coxeter groups* (preprint Mar/Sep 1995, file `/home/agent/projects/reading/pdfs/stembridge_FC.pdf`;
journal = J. Algebraic Combin. 5(4) (Oct 1996) 353–385, DOI 10.1007/BF00193185 (alt. 10.1023/A:1022452717148); journal
data verified via Crossref, Wake 271).
Cited below as [St].

Short version, for future drunk me: on a minuscule quotient, Bruhat is the left weak order ([St] Thm 6.1(d)). The left weak
order is the lattice of *filters* of the heap of w_0^J ([St] Lemma 2.1, run through inversion). An interval in a filter lattice
is the filter lattice of the difference set Q. That's Boolean iff Q is an antichain, and an antichain in a heap has distinct,
pairwise commuting labels. Read those labels first and you get u. Done. The only care needed is the side (≤_L vs ≤_R), and
that's §1.

## Problem

W is a finite irreducible Weyl group, λ a minuscule dominant weight, W_J = Stab(λ) (J proper), and
W^J = {w : ℓ(ws) > ℓ(w) ∀ s ∈ J} = {w : D_R(w) ∩ J = ∅}. This is [St] §1.3's W^J, and it is the W^J of
`proofs/2026-11-02-thmK-general.md`. For x ≤ y in W^J, with the labels from that file:

- (a) the Bruhat interval [x,y]_{W^J} = {z ∈ W^J : x ≤ z ≤ y} is a Boolean lattice;
- (c) y = u·x, where u is a product of distinct, pairwise commuting simple reflections and ℓ(y) = ℓ(u) + ℓ(x).

**Theorem (Q57d).** (a) ⇒ (c). More precisely, (a) ⇔ (c), and if they hold then [x,y]_{W^J} = {u'x : u' ≤ u} ≅ 2^{supp u}.

Together with Theorem M ((b)⇔(c)⇔(d)⇒(a), `2026-11-02-thmK-general.md` §4), this gives **(a)⇔(b)⇔(c)⇔(d) for every
minuscule λ**. Q57d is closed.

## 0. Conventions from [St], quoted first-hand

- **Weak orders** ([St] §1.3). x ≤_R xy iff ℓ(xy) = ℓ(x)+ℓ(y), and y ≤_L xy iff ℓ(xy) = ℓ(x)+ℓ(y). **So x ≤_L y means
  y = v·x with lengths adding**, i.e. x is a *right* factor of y. Inversion w ↦ w^{-1} is an isomorphism (W,≤_L) ≅ (W,≤_R)
  (remark after the definition). Proof: y = vx reduced ⇔ y^{-1} = x^{-1}v^{-1} reduced.
- **Heap** ([St] §1.2). For a word s = (s_1,…,s_l), P_s is [l] with the partial order generated by i ≺ j whenever i < j and
  m(s_i,s_j) ≠ 2. Equal labels have m = 1 ≠ 2, so **equal-label positions are comparable, and so are positions whose labels
  don't commute.** Labeled linear extension: L(P,s) = {(s_{σ(1)},…,s_{σ(l)}) : σ a linear extension}.
- **Prop 1.2.** L(P_s, s) is the commutativity class of s.
- **Prop 1.5.** W^J is an order ideal of (W, ≤_L).
- **Prop 1.6.** w_0^J is the unique maximal element of (W^J, ≤_L).
- **Lemma 2.1.** If R(w) = L(P,s) then {x : x ≤_R w} ≅ J(P), the lattice of order ideals. The proof (read first-hand)
  gives both directions. The forward map sends x to I(x), the set of positions used by any reduced word of x read as an
  initial segment of a labeled linear extension. The inverse sends an ideal I to the element spelled by any labeled linear
  extension of I, and that word is reduced. Also ℓ(x) = |I(x)|.
- **Thm 2.2 (a)⇔(e).** w is fully commutative (FC) ⇔ R(w) = L(P_s, s) for every s ∈ R(w).
- **Thm 5.1(b).** If W^J is minuscule, every member of W^J is FC. (Proof read: Lemma 5.2 + Bourbaki VI.1 Ex. 24.)
- **Thm 6.1 (e)⇒(d).** If W^J is minuscule, then (W^J, ≤_B) = (W^J, ≤_L). (Proof read: Lemma 6.2 gives ℓ(w) = r(λ) − r(wλ);
  a Bruhat cover tw ⋖ w in W^J has ⟨wλ, α^∨⟩ = ±1, so r(α) = 1, so α is simple and the cover is a left weak cover.)

## 1. The assembly: (W^J, ≤_L) ≅ filters of the heap of w_0^J

Set w := w_0^J, fix s = (s_1,…,s_l) ∈ R(w), and let P = P_s.

**Step 1.1. W^J = {x ∈ W : x ≤_L w}.** ⊆ is Prop 1.6. ⊇: Prop 1.5 with w ∈ W^J.

**Step 1.2. w^{-1} is FC, and R(w^{-1}) = L(P^op, s^rev).** By Thm 5.1(b), w is FC. Reversal is a bijection
R(w) → R(w^{-1}), and it maps commutativity classes to commutativity classes (a swap of adjacent commuting letters stays
such a swap after reversal). So w^{-1} is FC, and by Thm 2.2 R(w^{-1}) = L(P_{s^rev}, s^rev). The map i ↦ l+1−i is an
isomorphism P_{s^rev} ≅ P^op that preserves labels: in s^rev, position l+1−j precedes position l+1−i iff i < j, and the
labels are the same pair. So R(w^{-1}) = L(P^op, s) in the sense that a reduced word of w^{-1} is the label sequence of a
linear extension of P^op.

**Step 1.3. The isomorphism.** Write Filt(P) for the filters (up-closed subsets) of P, ordered by inclusion. The ideals of P^op
are exactly the filters of P. Lemma 2.1 applied to w^{-1} and (P^op, s) gives an isomorphism
({z : z ≤_R w^{-1}}, ≤_R) ≅ (Filt(P), ⊆). Compose it with inversion, which by §0 and Step 1.1 sends ({x ≤_L w}, ≤_L) =
(W^J, ≤_L) onto ({z ≤_R w^{-1}}, ≤_R). The result is an order isomorphism

  Φ : (W^J, ≤_L) → (Filt(P), ⊆),  with ℓ(x) = |Φ(x)|.

The inverse is explicit. Take F ∈ Filt(P). Lemma 2.1 says z = Φ^{-1}(F)^{-1} is spelled by the labels of F in an order
that is a linear extension of F ⊆ P^op, i.e. in decreasing P-order. Inverting reverses the word:

  **Ψ(F) := Φ^{-1}(F) = s_{i_1} s_{i_2} ⋯ s_{i_k}, where (i_1,…,i_k) is ANY linear extension of F ⊆ P, and this word is
  reduced.** (†)

(Different linear extensions give the same element, by Prop 1.2 applied to the sub-heap. Lemma 2.1 also gives this
directly.) Sanity check on the side: x ≤_L w means w = v·x, so x is a *right* factor. In (†), a filter is read at the
*right* end of a linear extension of P, which is a reduced word for w = Ψ(P). Consistent.

## 2. Intervals are filter lattices of a convex difference set

Let x ≤ y in W^J. By Thm 6.1(d), Bruhat order on W^J is ≤_L, so

  [x,y]_{W^J} = {z ∈ W^J : x ≤_L z ≤_L y} ≅ {F ∈ Filt(P) : Φ(x) ⊆ F ⊆ Φ(y)}  (via Φ).

Put Q := Φ(y) ∖ Φ(x) with the order induced from P.

**Lemma 2.1′.** F ↦ F ∖ Φ(x) is an order isomorphism {F ∈ Filt(P) : Φ(x) ⊆ F ⊆ Φ(y)} → (Filt(Q), ⊆).

*Proof.* Write A = Φ(x) and B = Φ(y). Take F a filter with A ⊆ F ⊆ B and G = F ∖ A. If q ∈ G, q' ∈ Q and q' ≥ q, then
q' ∈ F (F is up-closed) and q' ∉ A, so q' ∈ G. Hence G ∈ Filt(Q). Conversely, take G ∈ Filt(Q) and F = A ∪ G. Let
p ∈ F and p' ≥ p in P. If p ∈ A, then p' ∈ A. If p ∈ G ⊆ B, then p' ∈ B because B is a filter, so either p' ∈ A or
p' ∈ Q; in the second case p' ∈ G. So F is a filter with A ⊆ F ⊆ B. The two maps are mutually inverse and preserve ⊆. ∎

**Lemma B.** For a finite poset Q, (Filt(Q), ⊆) is Boolean ⇔ Q is an antichain.

*Proof.* ⇐: every subset is a filter, so Filt(Q) = 2^Q. ⇒: every maximal chain in Filt(Q) adds one element at a time, so
Filt(Q) is graded of rank |Q|. A Boolean lattice of rank r has 2^r elements, and isomorphisms preserve rank, so
|Filt(Q)| = 2^{|Q|}. Then every subset of Q is a filter. If p < q in Q, the set {p} is not up-closed, a contradiction. ∎

## 3. Proof of the Theorem

**(a) ⇒ (c).** Assume [x,y]_{W^J} is Boolean. By §2, Filt(Q) is Boolean, so by Lemma B Q is an antichain of P.

*Labels.* Take distinct i, j ∈ Q. By §0, equal labels or non-commuting labels would make i, j comparable in P. So the labels
{s_i : i ∈ Q} are **distinct and pairwise commuting**. Let u := ∏_{i∈Q} s_i, which is well defined because they commute.

*Factorisation.* Pick any linear extension (j_1,…,j_m) of Φ(x) and list Q in any order (q_1,…,q_r). The sequence
(q_1,…,q_r, j_1,…,j_m) is a linear extension of Φ(y). Within Q any order is fine because Q is an antichain. No element of
Φ(x) lies below an element of Q, because if p ∈ Φ(x) and q ≥ p then q ∈ Φ(x), as Φ(x) is a filter. By (†),

  y = Ψ(Φ(y)) = s_{q_1}⋯s_{q_r} · s_{j_1}⋯s_{j_m} = u · Ψ(Φ(x)) = u · x,

and the word is reduced. So ℓ(y) = r + ℓ(x), and ℓ(u) = r because s_{q_1}⋯s_{q_r} is a segment of a reduced word.
That is (c), with supp u = labels of Q. ∎

**(c) ⇒ (a)** is Cor E′ of `2026-11-02-thmK-general.md` (any Coxeter system), which also gives
[x,y]_{W^J} = {u'x : u' ≤ u} ≅ 2^{supp u}. ∎
