# (M) Master Identity — PROVED — Day 109 (2026-08-18)

## Statement

For every integer $k \geq 1$:
$$Q_k(-2, b, c) = (-1)^k \cdot c \cdot (c - k) \cdot \prod_{j=1}^{k-1}(c - j)^2 \quad (M)$$
where $Q_k(a, b, c)$ is Rick's h-template polynomial (pipeline in
`/home/agent/projects/code/2026-07-10-hk-three-var-fit.py`).

By $a \leftrightarrow b$ symmetry (a shifted-Schur symmetry, see §5),
the same formula holds for $Q_k(a, -1, c)$.

## Setup: pipeline as a shifted-Schur sum

Let $y = (y_1, y_2, y_3) := (a+2, b+1, c)$ — the shifted variables of
O-O (Def 1.2, $n = 3$). Let $V(y) = (y_1-y_2)(y_1-y_3)(y_2-y_3) = (a-b+1)(a-c+2)(b-c+1)$.

Define
$$ds_j(a, b, c) := \sum_{\mu \in \mathcal{S}_j} \kappa_\mu \det[(y_i)_{\downarrow \mu_j + 3 - j}]_{i,j=1}^3$$
where $\mathcal{S}_j$ is the set of partitions of $2j$ built by $j$ successive
vertical 2-strip additions to $\emptyset$, constrained to $\ell(\mu) \leq 3$,
and $\kappa_\mu$ counts distinct walks $\emptyset \to \mu$.

**V divides $ds_j$ (Vandermonde-Weyl):** for each $\mu$ contributing to $ds_j$,
the numerator determinant is $s^*_\mu(y_1, y_2, y_3) \cdot V(y)$; thus
$$\frac{ds_j}{V} = \sum_{\mu \in \mathcal{S}_j} \kappa_\mu s^*_\mu(y_1, y_2, y_3) \in \mathbb{Z}[a, b, c].$$

**Pipeline formula (impulse term $(2c)!\binom{j}{2c}$ dropped, valid for $c > j/2$):**
$$H_c(a, b, j) = (a + 3)_{c-1-j} \cdot (b + 2)_{c-j-1} \cdot \frac{ds_j}{V}, \tag{$H$}$$
where $(x)_L = x(x+1)\cdots(x+L-1)$ is the RISING Pochhammer.

**Since both sides of (M) are polynomials in $c$ of degree $\leq 2k$ (LHS by
Rick's pipeline analysis, RHS manifest), it suffices to prove (M) for $c > 2k$,
where the impulse never fires. Below, $c$ is taken sufficiently large without
further comment.**

**Binomial inversion:** $h_k = \sum_{j=0}^k (-1)^{k-j}\binom{k}{j} H_c(a, b, j)$.

**Definition:** $Q_k(a, b, c) := h_k / [(a+3)_{c-1-k}(b+2)_{c-1-k}]$.

## Lemma 1 (Rank-drop). For every $j \geq 0$:
$$\left.\frac{ds_j(a, b, c)}{V(a, b, c)}\right|_{a = -2} = b^{\underline{j}} \cdot (c-1)^{\underline{j}}, \tag{L1}$$
where $x^{\underline{j}} := x(x-1)\cdots(x-j+1)$ is the falling factorial.

### Proof of Lemma 1.

At $a = -2$: $y_1 = 0$. For any partition $\mu = (\mu_1, \mu_2, \mu_3)$
with $\mu_3 > 0$, the first row of $\det[(y_i)_{\downarrow \mu_j + 3-j}]$ has
entries $((0)_{\downarrow \mu_1 + 2}, (0)_{\downarrow \mu_2 + 1}, (0)_{\downarrow \mu_3})
= (0, 0, 0)$ (since each shift is $\geq 1$), so the determinant vanishes.

**Rank-drop:** only $\mu \in \mathcal{S}_j$ with $\ell(\mu) \leq 2$ contribute
to $ds_j |_{a = -2}$.

**Claim:** the unique partition $\mu \in \mathcal{S}_j$ with $\ell(\mu) \leq 2$
is $\mu = (j, j, 0)$, and its multiplicity is $\kappa_{(j,j)} = 1$.

*Proof of claim.* A vertical 2-strip added to a partition with $\ell \leq 2$
can either (i) add one cell to row 1 and one to row 2 (staying in 2 rows),
or (ii) start a new row 3. If we require the final $\mu$ to have $\ell \leq 2$,
only type (i) is allowed at every step. Type (i) requires the added cells to
be in valid Young-diagram positions, which forces them into columns $\nu_1 + 1$
(row 1) and $\nu_2 + 1$ (row 2) at the step $\nu \to \mu$. Starting from
$\emptyset$, this uniquely produces $\emptyset \to (1,1) \to (2,2) \to \cdots \to (j,j)$.
Hence there is a unique walk, $\kappa_{(j,j)} = 1$. $\square$

For $\mu = (j, j, 0)$, the shifts are $\mu_j + 3 - j = (j+2, j+1, 0)$.
The first row at $y_1 = 0$ is $(0, 0, 1)$ (since $(0)_{\downarrow 0} = 1$).
Expanding along row 1:
$$\det|_{y_1 = 0} = \det\begin{pmatrix}(y_2)_{\downarrow j+2} & (y_2)_{\downarrow j+1} \\ (y_3)_{\downarrow j+2} & (y_3)_{\downarrow j+1}\end{pmatrix}.$$

Using $(y_i)_{\downarrow j+2} = (y_i)_{\downarrow j+1} \cdot (y_i - j - 1)$:
$$= (y_2)_{\downarrow j+1}(y_3)_{\downarrow j+1}\bigl[(y_2 - j - 1) - (y_3 - j - 1)\bigr] = (y_2)_{\downarrow j+1}(y_3)_{\downarrow j+1}(y_2 - y_3).$$

With $y_2 = b+1$, $y_3 = c$:
- $(y_2)_{\downarrow j+1} = (b+1)b(b-1)\cdots(b-j+1) = (b+1) \cdot b^{\underline{j}}$;
- $(y_3)_{\downarrow j+1} = c(c-1)(c-2)\cdots(c-j) = c \cdot (c-1)^{\underline{j}}$;
- $y_2 - y_3 = b + 1 - c = -(c - b - 1)$.

Therefore $\det|_{a = -2} = -(b+1) \cdot b^{\underline{j}} \cdot c \cdot (c-1)^{\underline{j}} \cdot (c - b - 1)$.

Similarly $V|_{a = -2} = (-b - 1)(-c)(b - c + 1) = -(b+1) c (c - b - 1)$.

Dividing: $(ds_j/V)|_{a = -2} = \dfrac{-(b+1) b^{\underline{j}} c (c-1)^{\underline{j}}(c - b - 1)}{-(b+1) c (c - b - 1)} = b^{\underline{j}} (c-1)^{\underline{j}}$. $\blacksquare$

## Lemma 2 (Vandermonde-Chu variant). For any $u, v \in \mathbb{Q}[t]$ (or symbols) and $k \geq 0$:
$$\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}\,u^{\overline{k-j}} \cdot v^{\underline{j}} = (-1)^k (u - v)^{\overline{k}}, \tag{L2}$$
where $x^{\overline{m}} := x(x+1)\cdots(x + m - 1)$ is the RISING Pochhammer.

### Proof of Lemma 2.

$v^{\underline{j}} = v(v-1)\cdots(v-j+1) = (-1)^j (-v)^{\overline{j}}$.
So $(-1)^{k-j} v^{\underline{j}} = (-1)^{k-j}(-1)^j (-v)^{\overline{j}} = (-1)^k (-v)^{\overline{j}}$.

Then LHS $= (-1)^k \sum_j \binom{k}{j} u^{\overline{k-j}} (-v)^{\overline{j}} = (-1)^k (u + (-v))^{\overline{k}} = (-1)^k (u - v)^{\overline{k}}$

by the Chu-Vandermonde identity for rising factorials
$(A + B)^{\overline{k}} = \sum_j \binom{k}{j} A^{\overline{j}} B^{\overline{k-j}}$. $\blacksquare$

## Proof of (M).

Substituting Lemma 1 into ($H$) at $a = -2$ and using $(a+3)_{c-1-j}|_{a=-2} = (1)_{c-1-j} = (c-1-j)!$:
$$H_c(-2, b, j) = (c - 1 - j)! \cdot (b+2)_{c-j-1} \cdot b^{\underline{j}} \cdot (c-1)^{\underline{j}}.$$

Key cancellation: $(c - 1 - j)! \cdot (c-1)^{\underline{j}} = (c-1)!$ (both express $(c-1)! = (c-1)(c-2)\cdots 1$ factored at position $j$). Hence:
$$H_c(-2, b, j) = (c-1)! \cdot (b+2)_{c-j-1} \cdot b^{\underline{j}}.$$

Binomial inversion:
$$h_k(-2, b, c) = (c-1)! \sum_{j=0}^k (-1)^{k-j}\binom{k}{j}(b+2)_{c-j-1} b^{\underline{j}}.$$

Factor out $(b+2)_{c-1-k}$: since $(b+2)_{c-j-1} = (b+2)_{c-1-k} \cdot (b + c - k + 1)^{\overline{k-j}}$:
$$h_k(-2, b, c) = (c-1)!(b+2)_{c-1-k}\sum_{j=0}^k (-1)^{k-j}\binom{k}{j}(b + c - k + 1)^{\overline{k-j}} b^{\underline{j}}.$$

Apply Lemma 2 with $u = b + c - k + 1$, $v = b$: $u - v = c - k + 1$, so the sum equals $(-1)^k (c - k + 1)^{\overline{k}}$:
$$h_k(-2, b, c) = (-1)^k (c-1)!(b+2)_{c-1-k}(c-k+1)^{\overline{k}}.$$

Finally,
$$Q_k(-2, b, c) = \frac{h_k(-2, b, c)}{(a+3)_{c-1-k}(b+2)_{c-1-k}\big|_{a=-2}} = \frac{(-1)^k (c-1)!(b+2)_{c-1-k}(c-k+1)^{\overline{k}}}{(c-1-k)!(b+2)_{c-1-k}}$$
$$= (-1)^k \cdot \frac{(c-1)!}{(c-1-k)!} \cdot (c-k+1)^{\overline{k}} = (-1)^k \cdot (c-1)^{\underline{k}} \cdot (c-k+1)^{\overline{k}}.$$

**Expansion:**
$(c-1)^{\underline{k}} = (c-1)(c-2)\cdots(c-k)$ — factors $c-1, c-2, \ldots, c-k$.
$(c-k+1)^{\overline{k}} = (c-k+1)(c-k+2)\cdots c$ — factors $c-k+1, c-k+2, \ldots, c$.

Interleaving: factor $(c - k)$ appears once (only in falling), factor $c$ appears
once (only in rising), factors $c-1, c-2, \ldots, c-k+1$ each appear twice.

$$Q_k(-2, b, c) = (-1)^k \cdot c \cdot (c-k) \cdot \prod_{j=1}^{k-1}(c-j)^2. \qquad \blacksquare$$

## Remarks

**(R1) The proof does not use the full O-O machinery.** Coherence relations, the
characterization theorem, and the branching rule at $x_1 = 0$ all TURNED OUT
UNNECESSARY. What matters is:
1. The Vandermonde-Weyl factorization $\det = s^*_\mu \cdot V$ (which shows $V \mid ds_j$).
2. A first-row rank drop for individual determinants at $y_1 = 0$.
3. A unique surviving partition $\mu = (j, j, 0)$ in $\mathcal{S}_j$ with $\ell \leq 2$.
4. Vandermonde-Chu.

The rank drop for the ENSEMBLE $\mathcal{S}_j$ is more delicate than a
generic shifted-Schur rank drop because we need to know precisely WHICH
partitions survive.

**(R2) The $a \leftrightarrow b$ duality of (M).** Setting $b = -1$ instead of $a = -2$
corresponds to $y_2 = 0$ instead of $y_1 = 0$. By the same first-row rank
drop applied to the SECOND row (permuting rows of the determinant), the same
2x2 minor evaluation goes through, and one obtains
$Q_k(a, -1, c) = Q_k(-2, b, c)$. (The apparent asymmetry of the H_c coefficient
in $a$ vs $b$ washes out because the ambient shifted Schur is symmetric in
the $y_i$'s.)

**(R3) Consequences immediate to (M).**
- **Appendix F.** $Q_{2R}(-2, b, c) = -c(c - 2R)\prod_{j=1}^{2R-1}(c - j)^2$ — the
  special case $k = 2R$ of (M).
- **The uniform (★) proof** now reduces to (R) (level-$k$ recursion at Weyl
  wall $x_1 = x_2 = k$) and (LC) (leading coefficient formula).
  - (R) at $k = 0$ is exactly Appendix F, i.e., (M) at $k = 2R$.
  - (R) at $k \geq 1$ needs an analogous rank-drop argument at $y_1 = y_2 = k$
    (a Weyl-wall coincidence, not a boundary).

**(R4) The technique generalizes.** The proof pattern is:
1. Rank drop of the shifted-Schur ensemble at a specific slice.
2. Explicit evaluation of the surviving determinant(s).
3. Vandermonde-Chu on the resulting alternating binomial sum.

I expect this SAME pattern to work for (R). The rank drop is different (need
$y_1 = y_2 = k$ instead of $y_1 = 0$), but the ensuing arithmetic should collapse
similarly. **This is the Day 110 target.**

**(R5) Publishable form.** With (M) proved, half of the (★) theorem is done. The remaining piece is (R) — expected to yield to the same technique. Once both are proved, the standalone note "The Weyl-wall factorization of the 3-variable Jacobi–Trudi determinant" is drafteable at 4-6 pages.
