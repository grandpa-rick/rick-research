## 0. Answer in one line
For indecomposable X ∈ mod H_a(0) and Y ∈ mod H_b(0) with multiplicity-free tops:

> **X ⊠ Y is decomposable ⟺ X ⊠ □ and □ ⊠ Y are both decomposable.** Here □ = C_(1), the unique H_1(0)-module, and ⊠ = Ind_{H_a⊗H_b}^{H_{a+b}}.

(G*) says "unless both are projective". It only fails because "X ⊠ □ decomposes" is strictly weaker than "X projective". The 4 (+4 mirror) special Y of the Wake 290 tally are the smallest non-projective Y with □ ⊠ Y decomposable. Each of them is Y ≅ □ ⊠ S, with S a non-projective simple of H_3(0), and the failure (P ⊠ (□ ⊠ S) ≅ (P ⊠ □) ⊠ S with P ⊠ □ = two projectives) is just associativity.

## 1. Notation (as in the Q73 proof, §0–§2)
- **Objects.** H_n = H_n(0) is generated by π_i with π_i² = π_i. C_D is the 1-dim module with π_i ↦ [i ∈ D]. X ⊠ Y := Ind_B^{H_N}(X ⊗ Y), with B = H_a ⊗ H_b and N = a+b.
- **Words.** Basis T_w ⊗ v of X⊠Y, with w a shuffle and x(w) ∈ {A,B}^N the value word. Action rules AB / BA / AA / BB. Mackey pieces M_k, where k = number of B's among x_1..x_a. Res_B(X⊠Y) = ⊕_k M_k, with M_0 ≅ V := X⊗Y.
- **(H).** X and Y are indecomposable with multiplicity-free tops ⊕_i C_{D_i} and ⊕_j C_{E_j}. The top functionals are ε_i and δ_j, with ε_i(x_i) = 1 = δ_j(y_j).
- **Lemma 1 (Q73).** top(X⊠Y) is multiplicity-free, with labels Z_{ij0} = D_i ∪ (a+E_j) and Z_{ij1} = Z_{ij0} ∪ {a}, and functionals f_{ije}.
- **Lemma 2 (Q73).** Assume (H). X⊠Y is decomposable ⟺ there is a **witness**: k ≥ 1, (i,j), and u ∈ Hom_B(V, M_k) with f_{ij1}(u(x_i⊗y_j)) ≠ 0.
- **Region formula (Q73 §1).** f_{ij1}(T_{(ℓ|r)} ⊗ x⊗y) = [ℓ ok_i]·[r ok_j]·ε_i(x)δ_j(y), where ℓ = x_1..x_a and r = x_{a+1}..x_N.
- **Longest elements.** w_0^{X,k} is the longest element of ⟨s_{a−k+1},…,s_{a−1}⟩ (the last k positions of H_a), and w_0^{Y,k} is the longest element of ⟨s_1,…,s_{k−1}⟩ in H_b.
- **Fixed spaces.** For any module X, the joint fixed space of π_{a−k+1},…,π_{a−1} is exactly π_{w_0^{X,k}}X. Reason: π_q π_{w_0} = π_{w_0} for q in the range, and a fixed v satisfies π_{w_0}v = v.

**Definition.** For 1 ≤ k ≤ a put
- L̂_k(X) := Ind_{H_{a−k}⊗H_k}^{H_a}(Res_{H_{a−k}} X ⊠ C_{[k−1]}), where Res_{H_{a−k}} uses π_1..π_{a−k−1};
- **R_k(X)** :⟺ X is a direct summand of L̂_k(X).

Mirror version: for 1 ≤ k ≤ b put
- L̂'_k(Y) := Ind_{H_k⊗H_{b−k}}^{H_b}(C_{[k−1]} ⊠ Res' Y), where Res' uses π_{k+1},…,π_{b−1} renumbered 1..b−k−1;
- **L_k(Y)** :⟺ Y is a direct summand of L̂'_k(Y).

C_{[k−1]} = P_{(k)} is the 1-dim projective (π_i = 1 for all i).

**Fact F (Frobenius).** Hom_{H_a}(L̂_k(X), X) = {ζ_θ}, where ζ_θ(T_ℓ ⊗ x ⊗ 1) = T_ℓ π_{w_0^{X,k}} θ(x) and θ runs over End_{H_{a−k}}(Res X).
- *Proof.* By Frobenius reciprocity a map is determined by an H_{a−k}⊗H_k-map θ̃ : Res X ⊠ C_{[k−1]} → Res X.
- C_{[k−1]}-linearity says θ̃(x⊗1) is fixed by π_{a−k+1..a−1}, i.e. θ̃(x⊗1) = π_{w_0}θ̃(x⊗1).
- Put θ := θ̃(−⊗1), which is H_{a−k}-linear. Conversely, every θ gives θ̃ := π_{w_0}θ. This is H_{a−k}-linear because π_{w_0^{X,k}} commutes with π_1..π_{a−k−1} (disjoint, non-adjacent indices), and it is C_{[k−1]}-linear because π_q π_{w_0} = π_{w_0}. ∎

Write ζ := ζ_id. Then ζ_θ = ζ ∘ Ind(θ ⊠ id).

## 2. The theorem
**Theorem (one-box criterion).** Assume (H). The following are equivalent:
1. X ⊠ Y is decomposable;
2. there is k with 1 ≤ k ≤ min(a,b) such that R_k(X) and L_k(Y) hold;
3. R_1(X) and L_1(Y) hold;
4. X ⊠ □ and □ ⊠ Y are both decomposable.

### Step A: (1) ⇒ (2) (necessity; Q73 Lemma 3 plus its mirror)
- **R_k(X).** Q73 Lemma 3(b) uses only (H), never the shapes. A witness (k, i, j, u) gives maps X → L̂_k(X) → X whose composite g has ε_i∘g ≠ 0. So g ∉ ker ρ^X = J(End X) (Q73 Lemma 2 step 1 applied to X), and g is a unit. Hence R_k(X).
- **L_k(Y), same k.** Let φ be the automorphism π_i ↦ π_{N−i} of H_N. It maps B = H_a⊗H_b onto B' = H_b⊗H_a.
  - **Twist.** h⊗v ↦ φ(h)⊗v is an isomorphism φ^*(X⊠Y) ≅ (φ^*Y) ⊠ (φ^*X), where φ^* means twisting H_a or H_b by its own i ↦ n−i.
  - **Shuffles and pieces.** T_w ↦ T_{w_0 w w_0}, which sends (a,b)-shuffles to (b,a)-shuffles. On value words it reverses the word and swaps the letters A↔B. So the number of B's among the first a values (= k) becomes the number of new-B's among the first b values: a − (a−k) = k.
  - **Tops.** Top labels Z go to N−Z, so f_{ij1} goes to the f'_{ji1} of the new pair.
  - **Conclusion.** A witness at level k for (X,Y) is a witness at level k for (φ^*Y, φ^*X). Lemma 3(b) for that pair gives R_k(φ^*Y). Twisting back, using φ^*C_{[k−1]} = C_{[k−1]}, φ^* Ind_{(b−k,k)}(Res_{first} ⊠ C) = Ind_{(k,b−k)}(C ⊠ Res_{last}), and (φ^*)² = id, R_k(φ^*Y) becomes L_k(Y). ∎

### Step B: (2) ⇒ (1) (sufficiency; new)
Fix k with R_k(X) and L_k(Y).

1. **Units.** By R_k(X) and Fact F there are α: X → L̂_k(X) and θ with ζ_θ∘α a unit of End X. Replace α by α' := Ind(θ⊠id)∘α. Then ζ∘α' = ζ_θ∘α is a unit, so it acts on the multiplicity-free top by a scalar c ≠ 0 (End X is local, and J = ker ρ^X). Hence ε_i(ζ(α'(x_i))) = c for **every** i. In the same way, L_k(Y) gives β': Y → L̂'_k(Y) with δ_j(ζ'(β'(y_j))) = c' ≠ 0 for every j, where ζ'(T_r⊗1⊗y) = T_r π_{w_0^{Y,k}} y.
2. **The H_a⊗H_b structure of M_k.** Let B'' := H_{a−k}⊗H_k⊗H_k⊗H_{b−k} ⊆ H_a⊗H_b. Let V^tw be X⊗Y with the following B''-action:
   - H_{a−k} acts on X by π_1..π_{a−k−1};
   - the first H_k (inside H_a) acts on Y by π_1..π_{k−1};
   - the second H_k (inside H_b) acts on X by π_{a−k+1}..π_{a−1};
   - H_{b−k} acts on Y by π_{k+1}..π_{b−1}.

   Then M_k ≅ Ind_{B''}^{H_a⊗H_b} V^tw, with T_{(ℓ|r)}⊗v ↔ (T_ℓ⊗T_r)⊗v. *Proof.* The left word ℓ contains the a−k smallest A-values and the k smallest B-values, and r contains the rest. So within ℓ:
   - AA steps act by π_p on X with p ≤ a−k−1;
   - BB steps act by π_q on Y with q ≤ k−1;
   - AB and BA are the coset moves.

   The same holds for r with the roles reversed. These are exactly the word-model rules for the outer product of Ind_{(a−k,k)} and Ind_{(k,b−k)} (Q73 Lemma 3 step 1, done for both sides at once). The H_a- and H_b-rules touch disjoint letters, so they commute.
3. **The B''-map ψ.** Define ψ : (Res X ⊠ C_{[k−1]}) ⊗ (C_{[k−1]} ⊠ Res' Y) → V^tw by x⊗1⊗1⊗y ↦ π_{w_0^{X,k}}x ⊗ π_{w_0^{Y,k}}y. It is B''-linear:
   - factor 1: π_{w_0^{X,k}} commutes with π_1..π_{a−k−1};
   - factor 2: π_q π_{w_0^{Y,k}} = π_{w_0^{Y,k}}, matching the trivial action on C;
   - factor 3: the same with X;
   - factor 4: π_{w_0^{Y,k}} commutes with π_{k+1}..π_{b−1}.

   Inducing gives Ind(ψ) : L̂_k(X) ⊗ L̂'_k(Y) → M_k.
4. **The witness.** Put u := Ind(ψ) ∘ (α'⊗β') ∈ Hom_B(V, M_k). Write α'(x_i) = Σ_ℓ T_ℓ⊗x_ℓ⊗1 and β'(y_j) = Σ_r T_r⊗1⊗y_r. By the region formula,
   - f_{ij1}(u(x_i⊗y_j)) = (Σ_ℓ [ℓ ok_i] ε_i(π_{w_0}x_ℓ)) · (Σ_r [r ok_j] δ_j(π_{w_0}y_r)).
   - Claim: the first factor equals ε_i(ζ(α'(x_i))). Indeed ε_i(T_ℓ π_{w_0} x) = χ_{D_i}(T_ℓ)·χ_{D_i}(π_{w_0})·ε_i(x).
     - If [a−k+1,a−1] ⊄ D_i, then χ_{D_i}(π_{w_0}) = 0, so both sides vanish. (This case cannot occur, since ε_i ∘ ζ ∘ α' ≠ 0.)
     - Otherwise χ_{D_i}(T_ℓ) = [ℓ ok_i] (Q73 Lemma 3 step 6, which uses only the inclusion).
   - Likewise the second factor equals δ_j(ζ'(β'(y_j))) = c'.
   - So f_{ij1}(u(x_i⊗y_j)) = c·c' ≠ 0. This is a witness, and Lemma 2 gives (1). ∎

### Step C: (2) ⇒ (3) (R_k ⇒ R_1; no hypothesis needed)
Let k ≥ 2 and suppose R_k(X), via α' and ζ with ζα' a unit (Step B.1).
1. **ι.** The vector T_{s_1⋯s_{k−1}}⊗1⊗1 ∈ Ind_{(k−1,1)}(C_{[k−2]}⊠□) has value word B A⋯A. It is fixed by π_1 (BA) and by π_q for q ≥ 2 (AA, acting by 1). So 1 ↦ T_{s_1⋯s_{k−1}}⊗1⊗1 defines j : C_{[k−1]} → Ind(C_{[k−2]}⊠□). Inducing, and using transitivity of induction, gives an H_a-map
   ι : L̂_k(X) → Ind_{(a−1,1)}(W ⊠ □), with W := Ind_{(a−k,k−1)}^{H_{a−1}}(Res_{H_{a−k}}X ⊠ C_{[k−2]}).
2. **ζ''.** Let ζ'' : W → Res_{H_{a−1}} X be the Fact F map T⊗x⊗1 ↦ T π_{w_0''} x, where w_0'' is the longest element of ⟨s_{a−k+1},…,s_{a−2}⟩. It is H_{a−1}-linear, by Fact F inside H_{a−1}.
3. **ζ^{(1)}.** Let ζ^{(1)} : Ind_{(a−1,1)}(Res_{H_{a−1}}X ⊠ □) → X be T⊗x⊗1 ↦ Tx (Fact F with k = 1).
4. **Factorisation: ζ = ζ^{(1)} ∘ Ind(ζ''⊠id) ∘ ι.** Both sides are H_a-linear, so it suffices to compare them on the generators 1⊗x⊗1.
   - The right side gives T_{s_{a−k+1}⋯s_{a−1}} π_{w_0''} x.
   - s_1⋯s_{k−1}·w_0(⟨s_1..s_{k−2}⟩) is a length-additive factorisation of w_0(S_k): it maps i ↦ k+1−i. Check: for i < k, i ↦ k−i ↦ k−i+1, and k ↦ k ↦ 1.
   - Shifted to the last block this gives π_{w_0^{X,k}} x, which is the left side.
5. **Conclusion.** With α_1 := Ind(ζ''⊠id)∘ι∘α', we get ζ^{(1)}∘α_1 = ζ∘α', a unit. So X is a summand of L̂_1(X), i.e. R_1(X). The mirror statement L_k ⇒ L_1 follows by the twist φ^* of Step A. ∎

(3) ⇒ (2) is trivial (take k = 1).

### Step D: (3) ⟺ (4)
- Apply (1)⟺(2) to the pair (X, □). Here □ is simple, hence has a multiplicity-free top, and b = 1 forces k = 1. Also L_1(□) holds, since L̂'_1(□) = □. So X⊠□ is decomposable ⟺ R_1(X).
- Mirror: □⊠Y is decomposable ⟺ L_1(Y). ∎

## 3. Corollaries
1. **Projectives.** R_1(P) and L_1(P) hold for every projective P. The reason is that P⊠□ is projective with two-element top by Lemma 1, hence decomposable. So (G*)'s "⇐" is the special case where both factors are projective.
2. **(G*) holds for X ⟺ ¬R_1(X) or X is projective.** (G*) at X means: for every indecomposable Y with multiplicity-free top, X⊠Y is decomposable only if X and Y are both projective.
   - **Tightness.** If X is non-projective with R_1(X), the pair (X, P) with P projective violates (G*).
   - So the violators of (G*) are **exactly** the pairs with R_1(X), L_1(Y), and X or Y non-projective. The Wake 290 data are of this kind: 4 + 4 special modules, all paired with projectives.
3. **Recovers Q72(i).** For simples, R_1(C_I) ⟺ C_I ⊠ □ decomposable ⟺ (by Q72(i)) C_I projective. This is consistent with Q72(i) but does not reprove it, because Step D uses Q72-type input only through Lemma 2.
4. **Recovers Q73.** For shape modules, R_1(X_S) ⟺ X_S⊠□ = X_{S⋆(1)} decomposable ⟺ (Q73 strong form) the last component of S is a ribbon.
5. **Sufficient iso-form.** If Y ≅ Q⊠Y' with Q projective of size ≥ 1, then L_1(Y) holds. Proof: □⊠Y ≅ (□⊠Q)⊠Y' by associativity, and □⊠Q = two projectives. The converse ("L_1(Y) ⇒ Y ≅ Q⊠Y'") is **computed only** (see §4).

### Proposition S (structure of the special modules)
**Hypothesis (H∞) on X.** For every 0 ≤ t ≤ a, every indecomposable summand of Res_{H_{a−t}} X (using π_1..π_{a−t−1}) has a multiplicity-free top.

**Statement.** Let X be indecomposable with (H∞). Then R_1(X) holds ⟺ X ≅ X' ⊠ P_γ, where:
- P_γ is an indecomposable projective with |γ| ≥ 1;
- X' is an indecomposable summand of Res_{H_{a−|γ|}} X (X' = k if |γ| = a, i.e. X is projective).

The mirror statement holds for L_1.

*Proof.*
- **(⇐).** X⊠□ ≅ X'⊠(P_γ⊠□) = X'⊠P_{γ·1} ⊕ X'⊠P_{γ⊙1}, which is decomposable (both terms nonzero). By the Theorem (4)⇒(3) for the pair (X,□), R_1(X) holds. This uses only (H) for X.
- **(⇒), the loop.** Run the following for t = 1, 2, …. Invariant: X | Z^{(t)}⊠P_γ with |γ| = t, where Z^{(t)} is an indecomposable summand of Res_{H_{a−t}}X.
  - **Start, t = 1.** R_1(X) says X | Res X ⊠ □ = ⊕_ν Z_ν⊠□, where Z_ν runs over the indecomposable summands of Res_{H_{a−1}} X. By Krull–Schmidt, X | Z^{(1)}⊠□ for one of them, and P_{(1)} = □.
  - **Exit.** If Z^{(t)}⊠P_γ is indecomposable, then X ≅ Z^{(t)}⊠P_γ (an indecomposable summand of an indecomposable module), and we stop.
  - **Step.** Otherwise Z^{(t)} ≠ k, and (H) holds for (Z^{(t)}, P_γ): Z^{(t)} by (H∞), and P_γ because it has simple top. The Theorem (1)⇒(3) gives R_1(Z^{(t)}). So Z^{(t)} | Z^{(t+1)}⊠□ with Z^{(t+1)} an indecomposable summand of Res Z^{(t)}, hence of Res_{H_{a−t−1}}X.
  - **Re-establish the invariant.** X | Z^{(t+1)}⊠(□⊠P_γ) = Z^{(t+1)}⊠P_{1·γ} ⊕ Z^{(t+1)}⊠P_{1⊙γ}, using associativity and KLO Lemma 5.1 (Huang). By Krull–Schmidt, X divides one of these two terms.
- **Termination.** At t = a, Z^{(a)} = k and X | P_γ, so X ≅ P_γ. ∎

**Skew shapes satisfy (H∞).**
- Res_{H_{a−t}} X_{λ/μ} = ⊕_ν X_{ν/μ}^{⊕f^{λ/ν}} (Q73 §4 step 4).
- Each X_{ν/μ} = ⊕ X_S with X_S indecomposable and with multiplicity-free top (Q73 Cor 4' + strong form).

So for skew shape modules, R_1 ⟺ "last component is a ribbon" ⟺ X ≅ X'⊠P. This agrees with Q73.
