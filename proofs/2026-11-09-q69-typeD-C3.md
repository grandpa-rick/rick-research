## 1. Problem

(A) For a left cell Γ of a finite Coxeter group W and J ⊆ S:
 #{w ∈ Γ : L(w) ⊇ J} = ⟨[Γ], Ind_{W_J}^W sgn_J⟩.

(B) Let W = D_n. Then int A = {s ∈ A : all Δ-neighbours of s are in A}. A *candidate pair* in Γ is x ≠ z ∈ Γ with ∅ ≠ L(z) ⊆ int L(x). (★) says Γ has no candidate pair. The task is to decide (★) for every left-cell character type of D_n, n ≤ 8.

## 2. Proof of (A)

Let M be the convention-C module of Γ, with basis (e_x)_{x∈Γ}. Fix s ∈ S and write V_s := span{e_x : s ∈ L(x)}.

**Claim 1.** ker(1+s) = V_s.
- ⊇: (1+s)e_x = 0 for s ∈ L(x), by definition.
- ⊆: let m = Σ c_x e_x with (1+s)m = 0. For s ∉ L(x), (1+s)e_x ≡ 2e_x mod V_s, since all the extra terms e_y have s ∈ L(y). Also (1+s)V_s = 0. So 0 = (1+s)m ≡ 2 Σ_{s∉L(x)} c_x e_x mod V_s.
- Hence c_x = 0 whenever s ∉ L(x), and m ∈ V_s. ∎

**Claim 2.** The sgn_J-isotypic component of Res_{W_J} M is ⋂_{s∈J} ker(1+s).
- An element m lies in the sgn_J-isotypic component iff w·m = sgn(w)m for all w ∈ W_J.
- Since W_J is generated by J and sgn(s) = −1, this holds iff s·m = −m for all s ∈ J. ∎

**Conclusion.**
- By Claims 1 and 2, the sgn_J-isotypic component is ⋂_{s∈J} V_s. That is the coordinate subspace span{e_x : J ⊆ L(x)}, because each V_s is spanned by a subset of the same basis.
- Its dimension is #{x ∈ Γ : L(x) ⊇ J}.
- It also equals the multiplicity of sgn_J in Res_{W_J}[Γ], which is ⟨[Γ], Ind_{W_J}^W sgn_J⟩ by Frobenius reciprocity. ∎

**Remarks.**
1. **What the proof uses.** The proof uses nothing about KL except that M is a W-module given by W-graph formulas of this shape. So it holds for any W-graph and any field of characteristic ≠ 2. Semisimplicity is not needed, because isotypic = joint eigenspace only uses that W_J acts.
2. **Möbius inversion.** #{x ∈ Γ : L(x) = A} = Σ_{K ⊇ A} (−1)^{|K∖A|} ⟨[Γ], Ind_{W_K} sgn⟩. So the descent-set multiset of Γ, and with it (★), is a function of [Γ] alone.
3. **Type A sanity.** In type A, if [Γ] ↔ s_λ (with the appropriate sgn twist), this is ⟨s_λ, e_α⟩ = #{T ∈ SYT : Des ⊇ S(α)}, as required.
4. **Convention.** Convention C′ (s acts by +1 on descents) gives [Γ] ⊗ sgn and Ind 1_J instead. The set of constructible characters is ⊗sgn-stable, so the census below doesn't care which convention is used.
5. **Owner.** No-browse session. This is surely folklore: it's the W-graph form of "τ-invariant ↔ sign multiplicities", and Geck's induction-of-cells papers use the same restriction. I'm grading it *proved*, owner unverified, and claiming no novelty.

## 3. Computation (B)

**Model.** Irr(D_n) consists of the unordered bipartitions {α, β}, with α = β splitting into ±.
- Values on non-split classes come from bipartition Murnaghan–Nakayama: B_n class (λ⁺, μ⁻), with a negative cycle removed from β carrying an extra −1.
- The split difference χ⁺ − χ⁻ is ±2^{ℓ(ν)} χ^α(ν) on the split class (2ν, ∅)^±. The + class is the one meeting the standard S_n = ⟨s_1..s_{n−1}⟩.
- ⟨χ, Ind_{W_J} sgn⟩ is computed by fusing the classes of W_J = ∏ S_k × D_m into D_n. J containing exactly one leaf is handled by the diagram automorphism σ, which swaps χ^±.
- The constructible characters follow Lusztig's definition: truncated a-induction from the maximal parabolics S_k × D_{n−k} (1 ≤ k ≤ n−2), S_n and σ(S_n), plus ⊗sgn, recursively. Con of a type-A factor is Irr.
- a-values come from symbols: a = Σ_{pairs} min − the same quantity for the trivial symbol.
- Code: `prove285/dchar.py`.

## 4. Side lemma: Boundary kill (proved)

**Lemma.** Let J ⊊ S, let x, z ∈ W_J with x ≠ z, and suppose some s ∈ L(x) has m(s,t) = 3 for some t ∉ J. Then (x, z) is not a dominated twin in W.

*Proof.* Suppose it is a twin, so x, z ∈ Γ.
1. Elements of W_J have all left descents in J, so t ∉ L(x) and t ∉ L(z).
2. Write x = s·u. Then u = sx ∈ W_J has neither s nor t as a left descent, so u is minimal in ⟨s,t⟩u. Hence x = su has type {s}, and tx = tsu has type {t}. So *x = tx.
3. By (K5), μ̃(x, tx) = 1. Since s ∈ L(x) ∖ L(tx) and t ∈ L(tx) ∖ L(x), F2 gives tx ∈ Γ. So tx ∈ W_i(x).
4. By Theorem W(d), μ̃(tx, z) ≥ 1, so tx and z are comparable.
5. tx ≤ z is impossible. By the subword property every element ≤ z lies in W_J, but tx ∉ W_J, because t ∈ L(tx) ⊄ J.
6. So z < tx with μ(z, tx) ≠ 0, and t ∈ L(tx) ∖ L(z). Then F1 gives z = t·tx = x, a contradiction. ∎

Consequence: twins of a parabolic W_J ⊂ W with a descent adjacent to S∖J do not survive in W. In particular, the S_14 twins (all with s_12 ∈ L(x)) die in A_13 ⊂ D_14. So D-twins are D-native, and the table above is the right place to look for them.
