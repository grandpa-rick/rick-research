## Statement

Setting: LG(m,2m), type C_m, ω = ω_m, P the maximal parabolic, J = {1,…,m−1}, W_P = W_J ≅ S_m. Strict partitions κ, ρ
with parts ≤ m, identified with shifted diagrams D(·) inside the staircase {(a,b): 0 ≤ a ≤ b ≤ m−1} (row a, column b;
the **diagonal** of (a,b) is d = b−a). Write ρ ⊆ κ for D(ρ) ⊆ D(κ) and θ = κ/ρ = D(κ)∖D(ρ), with the induced
componentwise order. A **V-map** on θ is a strictly order-preserving g: θ → {e<o} with g = e on diagonal boxes
(long draft, before Prop `prop:wpeel`). Box weight β(x) = α_{m−d} for d ≥ 1, β(x) = ε_m for d = 0.

LS12 (arXiv:1203.3237, Cor 3.4, (3.6); dictionary in `proofs/2026-10-28-q47-ls12-cor34-read.md`): z_κ ∈ W^P is the minimal
representative with z_κω = −v_κ, ℓ(z_κ) = dim LG − |κ|. For w ∈ W, 𝒫^↓_{w,z} = {LS paths p of shape ω : ι(p) ≤ wW_P,
down(w,p) = z}, where down(w,p) = down(⋯down(down(w,τ_1),τ_2)⋯,τ_r) for p = (τ_1 > ⋯ > τ_r; a_1 < ⋯) and
down(w,τ) = max{v ≤ w : vW_P = τ} (Deodhar). The coefficient of [O_{w}] in [L^{−ω}]·[O_z] is
(−1)^{ℓ(w)−ℓ(z)} Σ_{p∈𝒫^↓_{w,z}} e^{−p(1)}.

**Theorem Q48.** Let ρ ⊆ κ. The map

  Φ(g) := (κ∖O(g) ; κ),  O(g) := g^{−1}(o),

(read as the two-direction path with τ_1 = coset of κ∖O, τ_2 = coset of κ, a_1 = ½, or as the straight path in direction
κ if O(g) = ∅) is a bijection {V-maps on θ} → 𝒫^↓_{z_ρ, z_κ}, and

  −Φ(g)(1) = v_κ + Σ_{x∈O(g)} β(x),  (−1)^{ℓ(z_ρ)−ℓ(z_κ)} = (−1)^{|θ|}.

So LS12 (3.6), pulled back to G/B, is literally Thm 4.20 (`thm:Tchev`) of the long draft term by term. Also
𝒫^↓_{w,z_κ} = ∅ for w ∈ W^P not of the form z_ρ with ρ ⊆ κ. This is the order-ideal fact (F1): ι(p) ≤ wW_P forces the coset
of w to lie above that of z_κ.

Equivalently:
  𝒫^↓_{z_ρ,z_κ} ↔ {λ : ρ ⊆ λ ⊆ κ, λ/ρ an antichain, κ/λ an antichain with no diagonal box}  (λ = κ ↔ straight path).

**Consequences.** (i) An independent proof, from LS12 alone, of the V(θ) count and hence of Thm 4.20 (non-equivariantly,
c_ρ = (−1)^{|θ|−1}V(θ)). It uses neither (G1)/(LS)/reciprocity nor BR12. It still needs (KT) only to say that the
[O_ρ] are a basis, because LS12 is a G/B statement. (ii) Since Σ_{ρ⊆κ}V(κ/ρ) counts the pairs (ρ,λ), the machine
also gives Σ_{κ,ρ} V(κ/ρ) = 3^m for m ≤ 5 (9, 27, 81, 243). That is an unproved side remark, recorded as `computed` only.

## Standard facts used

(F1) [Proctor; Buch–Ravikumar §2; draft §2] W^P ↔ shifted shapes μ ⊆ staircase, μ ↦ w_μ, ℓ(w_μ) = |μ|, w_μ ω = ε_μ (sign
vector, −1 exactly at positions m+1−k, k ∈ μ). Bruhat order on W^P is containment. If b is a box of diagonal d, its
**colour** is c(b) = m−d. Then w_{μ+b} = s_{c(b)} w_μ (lengths add). Hence w_ν = (word of ν/μ in a linear extension)·w_μ is
length-additive for μ ⊆ ν. The colour map is a bijection {diagonals} → {1..m}.

(F2) (trichotomy) For a shape μ and a colour c, exactly one of the following holds:
 (add) there is an addable box b of colour c, and s_c w_μ = w_{μ+b};
 (rem) there is a removable box b of colour c, and s_c w_μ = w_{μ−b};
 (neu) s_c w_μ = w_μ s_j for some j ∈ J, with ℓ(s_c w_μ) = ℓ(w_μ)+1.
*Proof.* Let p = m−c. For c < m, α_c^∨ = ε_c − ε_{c+1} and ⟨ε_μ, α_c^∨⟩ ≠ 0 iff exactly one of p, p+1 lies in μ. If p ∈ μ and
p+1 ∉ μ, then s_c turns the part p into p+1: one box is added, at diagonal p, and the result is strict because p+1 ∉ μ. If
p+1 ∈ μ and p ∉ μ, one box at diagonal p is removed. For c = m, ⟨ε_μ, ε_m⟩ = ±1, so a part 1 is added or removed. In both
cases s_c w_μ lies in the coset of μ±b and has length |μ|±1 = ℓ(w_{μ±b}). The minimal representative is the unique element
of minimal length in its coset, so s_c w_μ = w_{μ±b}. If the pairing is 0, then s_c w_μ = w_μ u with u ∈ W_P∖{e}, and
ℓ(w_μ u) = ℓ(w_μ)+ℓ(u) = ℓ(w_μ)±1 forces u = s_j and the sign +. Uniqueness of the box: on each diagonal the boundary of μ
has exactly one position. ∎

(F3) (lifting property, Deodhar's Property Z; Björner–Brenti, *Combinatorics of Coxeter Groups*, Prop. 2.2.7) Let s be
simple and sw < w. If sv > v, then v ≤ w ⇔ v ≤ sw. If sv < v, then v ≤ w ⇔ sv ≤ sw.

(F4) (subword property, BB Thm 2.2.2) If x = x_1x_2 with ℓ(x) = ℓ(x_1)+ℓ(x_2), then x_2 ≤ x and x_1 ≤ x.

(F5) (LS paths of shape ω_m; Littelmann Invent. Math. 116 (1994) §5.2; bonds = draft Lemma `lem:bonds`) A Bruhat cover of
cosets of W/W_P is "add one box" (F1). Its bond |⟨τω, β^∨⟩| is 2 for an off-diagonal box (β = ε_i ± ε_k short, coroot
= itself, pairing ±2) and 1 for a diagonal box (β = 2ε_i, coroot ε_i). An a-chain needs a·bond ∈ Z with 0<a<1, so a = ½ and all
steps have bond 2. Hence an LS path of shape ω_m is either straight (direction τ) or (τ_1 > τ_2; ½), and the latter exists iff
τ_1 = λ, τ_2 = κ with λ ⊊ κ and κ/λ free of diagonal boxes (add the boxes along any linear extension). Endpoints are
p(1) = τω, resp. (τ_1ω + τ_2ω)/2.

(F6) Rotation dictionary: z_κ = w_{κ^∨}, where D(κ^∨) = R(staircase ∖ D(κ)) and R(a,b) = (m−1−b, m−1−a) is the 180°
rotation. R preserves diagonals and reverses the order, so R(κ/ρ) = ρ^∨/κ^∨ as an anti-isomorphic poset. (Both sides are
in the coset of ε = −v_κ and have length dim − |κ|. Machine check: `dict_check.py`, m ≤ 4, 0 failures.) Antichains go to
antichains and diagonal boxes go to diagonal boxes.

Elementary shape facts (S). Let μ ⊆ ν be shapes. (S1) The maximal elements of ν/μ are exactly the removable boxes of ν that
are not in μ: if x ∈ ν∖μ and y > x in ν, then y ∉ μ because μ is an order ideal. (S2) The minimal elements of ν/μ are
addable boxes of μ. (S3) On a fixed diagonal the boxes are totally ordered: (a,a+d) < (a+1,a+1+d). If x < y lie on one
diagonal, then x+(0,1) is a staircase box with x < x+(0,1) < y, on a different diagonal. (S4) If b ∈ ν is removable and b ∈ μ,
then b is removable in μ.

## Lemma 0 (min-rep test)
Let z ∈ W^P and w ∈ W with z ≤ w. Then down(w, zW_P) = z ⇔ z s_j ≰ w for all j ∈ J. Moreover z ≤ every element of zW_P.
*Proof.* Every element of the coset is zu with ℓ(zu) = ℓ(z)+ℓ(u). If u ≠ e, write u = s_j u′ reduced. By (F4),
z ≤ zs_j ≤ zu. So some zu ≠ z lies below w iff some zs_j does. ∎

## Lemma 0′ (monotonicity)
If w ≤ w′ then down(w,τ) ≤ down(w′,τ). (The left side is in τ and lies below w′.) ∎

## Lemma A (the whole content)
Let μ ⊆ ν be shifted shapes and E(μ,ν) := {i ∈ J : w_μ s_i ≤ w_ν}. Then **E(μ,ν) = ∅ ⇔ ν/μ is an antichain.**
Equivalently, by Lemma 0 and (F6): **for ρ ⊆ λ, down(z_ρ, λ) = z_λ ⇔ λ/ρ is an antichain.**

*Proof.* Induction on |ν|. If ν = μ, then E = ∅ because ℓ(w_μ s_i) > ℓ(w_μ), and ∅ is an antichain. Let ν ≠ μ. For a
removable box b of ν with colour c, write s = s_c, so s w_ν = w_{ν−b} < w_ν. Write v = w_μ s_i, so ℓ(v) = |μ|+1.

(⇐) Let ν/μ be an antichain and choose any removable b of ν.
 – If b ∈ μ, then b is removable in μ (S4), so (rem) gives s w_μ = w_{μ−b} and sv = w_{μ−b}s_i < v. By (F3),
   v ≤ w_ν ⇔ w_{μ−b}s_i ≤ w_{ν−b}, so E(μ,ν) = E(μ−b,ν−b). The skew is (ν−b)/(μ−b) = ν/μ, still an antichain, and
   |ν−b| < |ν|, so the induction gives E = ∅.
 – If b ∉ μ, then b ∈ ν/μ is minimal there (antichain), hence addable at μ (S2), and (add) gives sw_μ = w_{μ+b} and
   sv = w_{μ+b}s_i > v. By (F3), E(μ,ν) = E(μ,ν−b). The skew is ν/μ minus b, an antichain, so the induction gives E = ∅.

(⇒) Let ν/μ be a non-antichain, with x < y in ν/μ. By (S1) some maximal element b ≥ y of ν/μ is a removable box of ν with
b ∉ μ, and b is not minimal in ν/μ. Let c be its colour. Then b is not addable at μ (S2 and non-minimality), so by (F2) the
colour c is in one of three cases.
 – (neu) s w_μ = w_μ s_j. Since b ∉ μ we have μ ⊆ ν−b, so w_μ ≤ w_{ν−b}. Then s·(reduced word of w_μ) is a reduced word
   (length +1) and a subword of s·(reduced word of w_{ν−b}), which is a reduced word for w_ν. Hence w_μ s_j = s w_μ ≤ w_ν,
   j ∈ E, and E ≠ ∅.
 – (add) via an addable box b′ ≠ b on b's diagonal. The diagonal boxes outside μ start at b′, so b′ < b and b′ ∈ ν/μ. Then
   sv > v, and (F3) gives E(μ,ν) = E(μ,ν−b). By (S3), b′ < b′+(0,1) < b. Both boxes lie in (ν−b)/μ, the second because it
   lies below b ∈ ν, is above b′ ∉ μ, and is ≠ b. So (ν−b)/μ is not an antichain, and the induction gives E ≠ ∅.
 – (rem) via a removable box b″ ∈ μ of colour c, with b″ ≠ b. The diagonal boxes of μ end at b″ and b ∉ μ, so b″ < b. Then
   sv = w_{μ−b″}s_i < v, and (F3) gives E(μ,ν) = E(μ−b″, ν−b), with μ−b″ ⊆ ν−b. The new skew contains b″ and
   b″+(0,1). The second is ∉ μ because b″ is removable, ∈ ν because it is ≤ b″+(1,1) ≤ b, and ≠ b because it is on another
   diagonal. These two boxes are comparable, so the induction gives E ≠ ∅. ∎

## Proof of Theorem Q48
**Step 1 (the down-lift set).** Let p ∈ 𝒫^↓_{z_ρ,z_κ}. By (F5) there are two cases.
 – Straight, direction τ. Then down(z_ρ,τ) ∈ τ equals z_κ, so τ = coset of κ. The condition ι(p) ≤ z_ρW_P says ρ ⊆ κ (F1).
   By Lemma A, down(z_ρ,κ) = z_κ ⇔ κ/ρ is an antichain.
 – Two directions (λ; κ′). The final element lies in κ′'s coset, so κ′ = κ. Also λ ⊊ κ with κ/λ diagonal-free (F5), and
   ι(p) = λ ≤ z_ρW_P, i.e. ρ ⊆ λ. Put d_1 = down(z_ρ, λ) ∈ λ-coset. *Claim: d_1 = z_λ.* If not, Lemma 0 gives z_λ s_i ≤ d_1
   for some i ∈ J. By (F1) and (F6), z_λ = x·z_κ length-additively, where x is the box word of R(κ/λ) = λ^∨/κ^∨. So
   z_λ s_i = x·(z_κ s_i), lengths add, and z_κ s_i ≤ z_λ s_i ≤ d_1 by (F4). As z_κ s_i ∈ κ-coset, this gives
   down(d_1,κ) ≥ z_κ s_i ≠ z_κ, a contradiction. So d_1 = z_λ, and Lemma A gives that λ/ρ is an antichain. Then
   down(z_λ,κ) = z_κ, and Lemma A again gives that κ/λ is an antichain.
 Conversely, suppose ρ ⊆ λ ⊆ κ with λ/ρ and κ/λ antichains and κ/λ diagonal-free. Then p = (λ;κ) (straight if λ = κ) is an
 LS path (F5) with ι(p) ≤ z_ρW_P, and by Lemma A, down(z_ρ,λ) = z_λ and down(z_λ,κ) = z_κ. So p ∈ 𝒫^↓_{z_ρ,z_κ}.
 This proves the "Equivalently" form.

**Step 2 (V-maps are the same set).** Given a V-map g, put A = g^{−1}(e) and O = g^{−1}(o). Strictness says that every
comparable pair x < y in θ has x ∈ A and y ∈ O. So A and O are antichains, O has no diagonal box, and λ := ρ ∪ A is an order
ideal of the staircase. (If x < y ∈ A, then x ∈ κ. If x ∈ θ, the pair x<y would force y ∈ O; so x ∈ ρ.) Thus κ/λ = O. Conversely,
given λ as in Step 1, set g = e on λ/ρ and g = o on κ/λ. If x < y in θ, they are not in the same antichain, and x ∈ κ/λ,
y ∈ λ/ρ is impossible because λ is an ideal. So g is strictly order-preserving and e on diagonal boxes. The two maps are
mutually inverse, and composing with Step 1 gives Φ.

**Step 3 (weights and sign).** O is an antichain of maximal elements of θ, so by (S1) it is a set of off-diagonal corners of
κ, with at most one per row. Removing the corner of a row with part p (diagonal d = p−1 ≥ 1) turns p into p−1. By the corner
condition, p−1 ∉ κ, and the new parts stay distinct. In v_λ − v_κ, coordinate m+1−p changes by +2 and coordinate m+2−p by
−2. So
  −Φ(g)(1) = −(z_λω + z_κω)/2 = (v_λ + v_κ)/2 = v_κ + Σ_{x∈O} (ε_{m+1−p} − ε_{m+2−p}) = v_κ + Σ_{x∈O} α_{m−d(x)}
           = v_κ + Σ_{x∈O} β(x).
(For O = ∅ the path is straight, with −p(1) = v_κ.) The sign is (−1)^{ℓ(z_ρ)−ℓ(z_κ)} = (−1)^{|κ|−|ρ|} = (−1)^{|θ|}. ∎

**Remark (why the bijection is forced).** The weights v_κ + Σ_{O}β determine O. The forced o-boxes (non-minimal maximal
elements) are fixed. The free ones are isolated boxes of θ, and two isolated boxes cannot share a diagonal (S3), so their β's
are distinct simple roots (and ε_m). Every monomial class therefore has size 1, and any weight-preserving bijection equals Φ.
The machine sees all classes of size 1 at m ≤ 3 (`dump.py`).
