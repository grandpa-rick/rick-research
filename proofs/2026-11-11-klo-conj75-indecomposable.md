## Statement (KLO 2310.20571, §7.2)
- **Convention.** H_n(0) is generated by π_i with π_i² = π_i.
- **Modules.** For a basic skew shape λ/μ, X_{λ/μ} has basis SYT(λ/μ) (KLO App. A). For T an SYT and 1 ≤ i ≤ n−1:
  - π_i T = T if i is strictly left of i+1;
  - π_i T = 0 if i and i+1 are in the same column;
  - π_i T = s_i T if i is strictly right of i+1.
- **Relation to M_P.** X_{λ/μ} ≅ M_P whenever sh(τ_P) = λ/μ.
- **Components.** Write λ/μ = C_1 ⋆ ⋯ ⋆ C_m for its connected components, with C_1 the north-east one. Components occupy pairwise disjoint row and column ranges, and C_s lies strictly north-east of C_t for s < t.
- **Ribbon.** A component is a ribbon if it contains no 2×2 square.

**Theorem (Conj 7.5).** If m ≥ 2 and no two consecutive components C_s, C_{s+1} are both ribbons, then X_{λ/μ} is indecomposable.

**Corollary (strong form).** For arbitrary λ/μ, X_{λ/μ} ≅ ⊕_S X_S, and every X_S is indecomposable.
- S runs over the shapes obtained by replacing each maximal run of r consecutive ribbon components with one connected ribbon, using one of the 2^{r−1} ·/⊙ concatenations (KLO Lemma 5.1, Rem. A.1(2)).
- So the number of indecomposable summands is ∏ 2^{r−1}. This is the Wake 289 computed pattern, now a theorem.

## 0. Conventions and the word model
- For D ⊆ [n−1], C_D is the 1-dim module with π_i ↦ [i ∈ D]. For a parabolic W_Z and w ∈ S_n, π_w acts on C_Z by [w ∈ W_Z].
- Fix modules X over H_a = H_a(0) and Y over H_b, with N = a+b and B := H_a ⊗ H_b ⊆ H_N (generators π_i, i ≠ a). Let V := X ⊗ Y and X ⊠ Y := H_N ⊗_B V.
- **Basis.** X ⊠ Y has basis-free decomposition ⊕_w T_w ⊗ V over shuffles w (minimal left coset representatives). Encode w by the word x(w) ∈ {A,B}^N over *values*: x_v = A iff w^{-1}(v) ≤ a.
- **Action of π_i on T_w ⊗ v** (Q72 proof §0, valid for any V), by the letters (x_i, x_{i+1}):
  - **AB:** T_{s_i w} ⊗ v.
  - **BA:** T_w ⊗ v.
  - **AA:** T_w ⊗ π_p v, where p = rank of i among the A-values.
  - **BB:** T_w ⊗ π_{a+q} v, where q = rank of i among the B-values. Here π_{a+q} acts on Y as π_q.

**Lemma W (tableau = word model; JKLO Lemma 4 / KLO Prop A.2(1)).** Let S and S' be basic skew shapes. Then T_w ⊗ T ⊗ T' ↦ (the filling of S⋆S' with w(T) on S and w(a+T') on S') is an isomorphism X_S ⊠ X_{S'} → X_{S⋆S'}.

*Proof.*
- **Bijection on bases.** S⋆S' has no order relations between S-cells and S'-cells, so an SYT of S⋆S' is exactly a value set together with two standardised SYT.
- **Action.** Every S-cell is strictly right of, and in a different row from, every S'-cell. So the tableau rule for i ∈ S, i+1 ∈ S' gives s_i (word rule AB). For i ∈ S', i+1 ∈ S it gives the identity (BA). If both lie in S, the rule is the X_S rule for π_p, with p the rank, which is AA. BB is the same on the S' side. ∎

**Mackey splitting.** Let M_k := ⊕_{k(w)=k} T_w ⊗ V, where k(w) = #{B-letters among x_1..x_a}. Then Res_B(X⊠Y) = ⊕_{k=0}^{min(a,b)} M_k as B-modules, with M_0 = 1⊗V ≅ V.
- *Proof.* For i ≠ a the four rules never move a letter across the cut between values a and a+1.

## 1. Tops and the criterion
**Standing hypothesis (H).** X and Y are indecomposable, with multiplicity-free tops top X = ⊕_{i∈I} C_{D_i} and top Y = ⊕_{j∈J} C_{E_j}. Let ε_i : X → C_{D_i} and δ_j : Y → C_{E_j} be the top functionals, and fix x_i, y_j with ε_i(x_i) = 1 and δ_j(y_j) = 1.

**Lemma 1 (top).** top(X⊠Y) = ⊕_{i,j,e} C_{Z_{ije}}, multiplicity-free, where
- Z_{ij0} = D_i ∪ (a+E_j),
- Z_{ij1} = Z_{ij0} ∪ {a}.

The corresponding functional is f_{ije}(T_w ⊗ v) = [w ∈ W_{Z_{ije}}]·(ε_i⊗δ_j)(v).

*Proof.*
- Frobenius gives Hom(X⊠Y, C_Z) ≅ Hom_B(V, C_Z|_B) = Hom(X, C_{Z∩[a−1]}) ⊗ Hom(Y, C_{(Z−a)∩[b−1]}). This is 1-dim exactly for Z = Z_{ije}.
- The extension of β ∈ Hom_B(V, C_Z) is T_w⊗v ↦ χ_Z(π_w)β(v).
- The sets Z_{ije} are pairwise distinct. ∎

**Lemma 2 (indecomposability criterion).** Assume (H) and put M = X⊠Y. Then M is decomposable iff there exist k ≥ 1, i, j, and u ∈ Hom_B(V, M_k) with f_{ij1}(u(x_i⊗y_j)) ≠ 0.

*Proof.*
1. **The map ρ.** Every φ ∈ End M acts on the multiplicity-free top by scalars, which gives an algebra map ρ : End M → k^{I×J×2}.
   - ker ρ consists of maps into rad M = ∩ ker f_{ije}, hence of nilpotents. So ker ρ ⊆ J(End M).
   - im ρ is reduced, hence semisimple, so J(End M) = ker ρ and End M/J ≅ im ρ ≅ k^s, where s is the number of summands of M.
   - In particular, M is indecomposable iff im ρ = k·1.
2. **Frobenius.** φ corresponds to u = φ|_{1⊗V} ∈ Hom_B(V, Res M) = ⊕_k Hom_B(V, M_k). Write u = Σ u_k.
3. **k = 0.** u_0 ∈ End_B(V) = End X ⊗ End Y. Both rings are local, and ρ^X, ρ^Y take scalar values c(e)·1 on them, by step 1 applied to X and Y. Since f_{ije}|_{M_0} = ε_i⊗δ_j, each f_{ije} contributes the same scalar c_0 from u_0.
4. **k ≥ 1.** f_{ij0} vanishes on M_k, because a shuffle w ≠ id has s_a in every reduced word.
5. **Assembling.** ρ(φ)_{ij0} = c_0 and ρ(φ)_{ij1} = c_0 + Σ_{k≥1} f_{ij1}(u_k(x_i⊗y_j)). The u_k can be chosen independently of u_0, which gives the claim. ∎

**Region formula.** Let [α, β] be the component of Z_{ij1} containing a. Then α = a − r' and β = a + s', where:
- r' = length of the run a−1, a−2, … ∈ D_i;
- s' = length of the run 1, 2, … ∈ E_j.

For a shuffle w:
- w ∈ W_{Z_{ij1}} ⟺ w ∈ W_{[α,β]}, since a shuffle has trivial factor in every component of Z lying inside [1,a−1] or [a+1,N−1];
- ⟺ x_1 = ⋯ = x_{α−1} = A and x_{β+2} = ⋯ = x_N = B. (Q72 proof (2.1).)

## 2. Key Lemma: a witness makes X a summand of a smaller induced module
**Lemma 3.** Assume (H), and let k, i, j, u be a witness as in Lemma 2. Then:
- (a) [a−k+1, a−1] ⊆ D_i and [1, k−1] ⊆ E_j;
- (b) X is a direct summand of L̂ := Ind_{H_{a−k}⊗H_k}^{H_a}(Res_{H_{a−k}} X ⊠ C_{[k−1]}), via maps X → L̂ → X whose composite g satisfies ε_i∘g ≠ 0.

*Proof.*
1. **M_k as an H_a-module.** Cut each word as x = (ℓ | r), with ℓ = x_1..x_a holding k B's and r = x_{a+1}..x_N holding k A's.
   - For i < a, the rules of §0 change only ℓ.
   - AA at i acts by π_p on X with p ≤ a−k−1, since all left values lie below all right values.
   - BB acts by π_q on Y with q ≤ k−1.
   - Hence M_k|_{H_a} ≅ ⊕_r L̃_r with every L̃_r ≅ L̃ := Ind_{H_{a−k}⊗H_k}^{H_a}(X|_{H_{a−k}} ⊠ Y|_{H_k}), written in the word model with left words ℓ.
2. **The functional on a copy.** By the region formula, f_{ij1}(T_{(ℓ|r)} ⊗ x⊗y) = [ℓ_1..ℓ_{α−1} = A]·[r ok]·ε_i(x)δ_j(y). On each copy L̃_r with r ok, the functional λ̃(T_ℓ⊗x⊗y) := [ℓ ok] ε_i(x) δ_j(y) is f_{ij1}|_{L̃_r}, so it is H_a-linear into C_{D_i}.
3. **Choice of copy.** Ψ : X → M_k, x ↦ u(x⊗y_j), is H_a-linear. Since f_{ij1}(Ψ(x_i)) ≠ 0, some copy r has λ̃(Ψ_r(x_i)) ≠ 0.
4. **Proof of (a).** λ̃ ≠ 0 needs a left word whose k B's lie in [α, a], so k ≤ r'+1, which gives the first inclusion.
   - δ_j|_{Y|_{H_k}} : Y → C_{E'}, with E' := E_j ∩ [k−1], is H_k-linear. So λ̃ = λ̂ ∘ Ind(id ⊠ δ_j), where λ̂ on Ind(X|_{H_{a−k}} ⊠ C_{E'}) is λ̂(T_ℓ⊗x⊗1) = [ℓ ok] ε_i(x). λ̂ is H_a-linear because Ind(id⊠δ_j) is onto.
   - At ℓ = A^{a−k}B^k (w = id), apply π_{a−k+q} for q ∈ [1,k−1]. The left side gives [q ∈ E'] by BB, and the right side gives χ_{D_i}(π_{a−k+q}) = 1 by the first inclusion. Hence E' = [k−1].
5. **The return map ζ.** θ(x⊗1) := π_{w_0^{(k)}} x, where w_0^{(k)} is the longest element of S_{[a−k+1,a]}.
   - θ is H_{a−k}⊗H_k-linear X|_{H_{a−k}} ⊗ C_{[k−1]} → X: π_{w_0^{(k)}} commutes with H_{a−k}, and π_{a−k+q} π_{w_0^{(k)}} = π_{w_0^{(k)}}.
   - Frobenius gives ζ : L̂ → X, ζ(T_ℓ⊗x⊗1) = T_ℓ π_{w_0^{(k)}} x.
6. **ε_i∘ζ = λ̂.** ε_i(T_ℓ π_{w_0^{(k)}} x) = χ_{D_i}(T_ℓ)·χ_{D_i}(π_{w_0^{(k)}})·ε_i(x).
   - The middle factor is 1 by (a).
   - For an (a−k,k)-shuffle ℓ, ℓ ∈ W_{D_i} ⟺ ℓ ∈ W_{[α,a−1]}, where (as in the region formula) W_{[p,q]} := ⟨s_p,…,s_q⟩ is a GENERATOR interval, i.e. the symmetric group on the values {α,…,a}. Reason: ℓ's right descents lie in {a−k}, and the other components of D_i lie in [1, α−2] ⊆ [1, a−k−1], so their factors of ℓ are trivial. (Edge case k = r'+1: a−k = α−1 ∉ D_i, both sides force ℓ = id = A^{a−k}B^k.) Then ℓ ∈ W_{[α,a−1]} ⟺ ℓ fixes values 1..α−1 ⟺ ℓ_1..ℓ_{α−1} = A, i.e. "ℓ ok". So ε_i∘ζ = λ̂. (Cold-read NIT fixed 2026-11-11: previously written W_{[α,a]}, a value-interval, inconsistent with the generator-interval convention of the region formula.)
7. **Conclusion.** g := ζ ∘ Ind(id⊠δ_j) ∘ Ψ_r ∈ End X has ε_i(g(x_i)) = λ̃(Ψ_r(x_i)) ≠ 0. So g ∉ ker ρ^X = J(End X), hence g is a unit of the local ring End X. ∎

## 3. Shape input
**Lemma 4 (connected shapes; KLO Lemma 5.3(1), 5.4(1), Thm 3.9).** Let C be connected with row-superstandard tableau T_0. Then X_C has simple top C_{D_C}, where D_C = {i : i, i+1 in the same row of T_0}. Its top functional is ε_C(T) = [T = T_0].

*Proof.*
- **Simple top.** By KLO Lemma 5.4(1) the projective cover is P_{α_proj(C)}, which is indecomposable for an ordinary composition. Its label is D_C, the set of i with π_i T_0 = T_0. (Cross-checked against the Wake 289 sweep top data.)
- **σ explicitly.** In the interval model (KLO Thm 3.9/Lemma 3.2), T_0 ↦ σ := read_{τ_0}(T_0). This reading takes rows right-to-left, top row first, so σ concatenates *decreasing* runs on consecutive value blocks, one block per row. Hence Des_L(σ) = D_C, and σ is the longest element of W_{D_C}.
- **Reachability.** Every γ ≠ σ in [σ,ρ]_L is uσ for some u ≠ e with ℓ(uσ) = ℓ(u)+ℓ(σ). A reduced word of u gives a saturated ascending chain inside [σ,γ] ⊆ [σ,ρ]_L, so γ = π_u σ and ε(γ) = [u ∈ W_{D_C}]·ε(σ).
- **Vanishing.** If u ∈ W_{D_C} with u ≠ e, then uσ ∈ W_{D_C} would have length > ℓ(σ), which is the maximum. So ε(γ) = 0 for every γ ≠ σ. ∎

**Corollary 4'.** By Lemmas 1, W and 4 and induction on the number of components, every X_{λ/μ} has a multiplicity-free top, of size 2^{m−1}.

**Lemma 5 (support).** Let X = X_{C_1⋆⋯⋆C_j} with C_j not a ribbon, and let ℓ_last be the length of C_j's last row (the bottom row of the shape). Let ε be a top functional of X with label D ⊇ [a−k+1, a−1], k ≥ 1. Then:
- k ≤ ℓ_last;
- if ε(T) ≠ 0, the values a−k+1..a of T sit in the last k cells of the bottom row.

*Proof.*
- **Bound on k.** D ∩ [a−|C_j|+1, a−1] is a shift of D_{C_j}, whose final run has length ℓ_last − 1. So k ≤ ℓ_last.
- **j = 1.** By Lemma 4 only T = T_0 qualifies, and T_0 has a−k+1..a at the end of the last row.
- **j ≥ 2.** Write X = X' ⊠ X_{C_j}, using Lemma W with A = X'-letters and B = C_j-letters. Let a' = a − |C_j|. By Lemma 1, ε = f_{i'e} with ε(T_w⊗x'⊗y) = [w ∈ W_Z] ε'(x') ε_{C_j}(y).
  - ε_{C_j}(y) ≠ 0 forces y = T_0^{C_j}.
  - If e = 0, then w = id. If e = 1, then w ∈ W_{[α,β]} with β = a' + ℓ_first(C_j) − 1, so w fixes every value > a' + ℓ_first(C_j).
  - Since C_j has at least 2 rows, |C_j| ≥ ℓ_first + ℓ_last ≥ ℓ_first + k. So the values a−k+1..a are among the fixed ones, and sit in their T_0^{C_j} positions: the last k cells of the last row. ∎

**Lemma 6 (non-projectivity; NOT used in §4, where the contradiction comes from Thm 5.5; kept as a remark).** Let C be connected and not a ribbon. Then X_C is not projective.

*Proof.*
- X_C has simple top, with projective cover P_α, α = α_proj(C). Let R_α be the ribbon with the same rows; P_α ≅ X_{R_α} (KLO Rem. A.1(2)).
- Identify cells by (row, index in row).
- **SYT(C) ⊆ SYT(R_α).** The only R_α relation between rows r and r+1 is (r,1) < (r+1, last). In C, (r,1) lies above a cell of row r+1, and that cell is ≤ (r+1, last).
- **Strictness.** If rows r and r+1 of C overlap in o ≥ 2 columns, C forces (r,o) < (r+1,last). In R_α these two cells are incomparable: the up-set of (r,o) is the rest of row r. So some SYT of R_α violates C.
- Hence dim X_C < dim P_α, and X_C ≇ P_α. ∎

**Lemma 7 (rotation).** T ↦ T°, rotating by 180° and replacing each value v by n+1−v, gives X_{(λ/μ)°} ≅ φ^*X_{λ/μ}, where φ(π_i) = π_{n−i}. Also (C_1⋆C_2)° = C_2°⋆C_1°, and ribbons go to ribbons.

*Proof.* "i strictly left of / same column as / strictly right of i+1 in T" is equivalent to "n−i strictly left of / same column as / strictly right of n−i+1 in T°". ∎

## 4. Proof of the Theorem
Induction on n = |λ/μ|. The case m = 1 is KLO Prop 7.3(1): simple top implies indecomposable.

Let m ≥ 2 and assume the Theorem for all sizes < n. The Corollary at sizes < n follows from the Theorem there together with KLO Lemma 5.1, Rem. A.1(2) and Lemma W.

1. **Choose a split.** Pick j < m with C_j not a ribbon. If there is none, the no-adjacent-ribbons hypothesis forces m = 2, with C_1 a ribbon and C_2 not. Lemma 7 then replaces λ/μ by its rotation (C_2°⋆C_1°), with j = 1.
2. **Set up (H).** Put X = X_{C_1⋆⋯⋆C_j} and Y = X_{C_{j+1}⋆⋯⋆C_m}.
   - Both are indecomposable by induction, since their sizes are < n and they inherit the hypothesis. A single component is covered by Prop 7.3(1).
   - Their tops are multiplicity-free by Cor 4'. So (H) holds, and X_{λ/μ} ≅ X ⊠ Y by Lemma W.
3. **Suppose X⊠Y is decomposable.** Lemma 2 gives a witness (k, i, j, u).
   - Lemma 3(a) gives D_i ⊇ [a−k+1, a−1], and Lemma 5 gives k ≤ ℓ_last(C_j).
   - Lemma 3(b): X is a summand of L̂ with ε_i∘g ≠ 0.
4. **Restrict to one piece.**
   - Res_{H_{a−k}} X = ⊕_ν Q_ν. Here Q_ν := span{T : T^{-1}[1,a−k] = ν}, and Q_ν ≅ X_{ν/μ}^{⊕ f^{λ/ν}}, since π_i with i < a−k only sees the cells of ν.
   - So L̂ = ⊕_ν L̂_ν, and g = Σ_ν ζ ι_ν p_ν Ψ'' (Ψ'' as in Lemma 3).
   - End X is local, so some term g_ν is a unit. Then ε_i∘g_ν ≠ 0, so λ̂ ≠ 0 on L̂_ν.
   - By Lemma 5 this forces ν = ν_0 := λ/μ minus the last k cells of the bottom row. Note f^{λ/ν_0} = 1.
   - Hence X is a direct summand of L̂_{ν_0} ≅ X_{ν_0/μ} ⊠ X_{(k)} ≅ X_{S_0}, where S_0 := C_1⋆⋯⋆C_{j−1}⋆C_j^−⋆(k) (Lemma W; C_{[k−1]} = X_{(k)} is the one-row module). C_j^− may itself split as C_j'⋆(row segment).
5. **Contradiction.** |S_0| = a < n, so the Corollary gives X_{S_0} ≅ ⊕ X_S with every X_S indecomposable.
   - In every such S the last component is a ribbon: the final run of ribbons contains (k) and merges into one ribbon.
   - By Krull–Schmidt, X ≅ X_S for one of these S. By KLO Thm 5.5, S = C_1⋆⋯⋆C_j.
   - But the last component of C_1⋆⋯⋆C_j is C_j, which is not a ribbon.

So X⊠Y is indecomposable. ∎

**Corollary proof.** Merge adjacent ribbons using X_{R}⊠X_{R'} ≅ P_γ⊠P_{γ'} ≅ P_{γ·γ'} ⊕ P_{γ⊙γ'} ≅ X_{R''} ⊕ X_{R'''} (KLO Lemma 5.1 and Rem. A.1(2)), associativity of ⊠, and Lemma W. Each resulting X_S is indecomposable by the Theorem. ∎

## 5. Why it works (and the negative controls)
- **Ribbon at the end of X.** If C_j is a ribbon, Lemma 3 gives no contradiction. X = X_{…⋆R} genuinely *is* a summand of X_{…⋆R^-⋆(k)}: one merge pattern reproduces R. That is exactly the disconnected-ribbon splitting of KLO Prop 7.3(2).
- **(G*) is false.** The tempting general statement is "Ind of two indecomposables is indecomposable unless both are projective". It is **false**: `gstar.py` finds 56 counterexamples among weak-Bruhat interval modules with a+b ≤ 7. For example, C_{(1)} ⊠ Y decomposes for some non-projective indecomposable interval modules Y of H_4(0).
- **What does the work.** Shape modules escape (G*)'s failure through two ingredients: the support Lemma 5, which pins the summand to one restriction piece, and the classification Thm 5.5, which makes "summand of X_{S_0}" decidable by comparing last components.
- **Relation to Q72(i).** Q72(i) is the same Lemma 2 + Lemma 3 skeleton with 1-dim factors. There, Lemma 3's L̂ becomes L_k and the contradiction comes from Norton.
