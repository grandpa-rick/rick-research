## Statement

Let $j = 2l+1$ (odd), $\mu^{(m)} := (2l+1, l+1+m, l-m)$ for $m \in \{0,1,\ldots,l\}$. Define
$$\bar s^*_\mu(s) := [t^{d_\mu}]\,s^*_\mu(u, y, c)\big|_{u=t,\ y+c=s,\ yc=t}, \qquad d_\mu = \mu_1 + \lfloor(\mu_2+\mu_3)/2\rfloor.$$
For our family $d_\mu = 3l+1$ (independent of $m$).

**Identity (C1):**
$$\boxed{\bar s^*_{\mu^{(m)}}(j) = (-1)^m \delta_{m,l}.}$$

(Equivalently, with $\alpha_m := (-1)^m(m+1)$ (Day 118 Obs 3) and $\beta_m := \bar s^*_{\mu^{(m)}}(0)$:
$$\beta_m + j\alpha_m = (-1)^m \delta_{m,l},$$
which forces $\beta_m = (-1)^{m+1}[(m+1)(2l+1) - \delta_{m,l}]$.)

## Setup: the (A, B) reduction

Fix $j = 2l+1$. Under $y+c = j$, $yc = t$, the pair $(y,c)$ satisfies $y^2 - jy + t = 0$ (and $c = j-y$).

For any integer $a \ge 0$, reduce the falling factorial $[y]_a$ modulo $y^2 - jy + t$:
$$[y]_a \equiv A_a(t)\, y + B_a(t) \pmod{y^2 - jy + t}.$$
The polynomials $(A_a, B_a) \in \mathbb{Z}[j][t]$ satisfy the recursion (using $y^2 = jy - t$ and $[y]_{a+1} = [y]_a(y-a)$):
$$A_{a+1} = (j-a) A_a + B_a, \qquad B_{a+1} = -t A_a - a B_a,$$
with $A_0 = 0, B_0 = 1$.

Since $c = j-y$, $[c]_a \equiv A_a c + B_a = -A_a y + (A_a j + B_a)$.

**Degrees.** From the recursion, by induction:
$$\deg_t A_a = \left\lfloor \frac{a-1}{2} \right\rfloor, \qquad \deg_t B_a = \left\lfloor \frac{a}{2} \right\rfloor.$$

---

## Weyl formula reduction

$s^*_\mu(u,y,c) = \dfrac{\det[[x_i]_{k_j}]_{i,j=1..3}}{V(u,y,c)}$ with $k = (\mu_1+2, \mu_2+1, \mu_3)$; for our family $k = (2l+3,\ l+2+m,\ l-m)$.

Expand the numerator determinant along the first row:
$$\det = [u]_{k_1} M_{k_2, k_3} - [u]_{k_2} M_{k_1, k_3} + [u]_{k_3} M_{k_1, k_2},$$
where $M_{a,b} := [y]_a[c]_b - [y]_b[c]_a$ is the $2\times 2$ minor over rows $(y,c)$.

**Key computation.** Using $[y]_a \equiv A_a y + B_a$ and $[c]_a \equiv -A_a y + (A_a j + B_a)$:
$$M_{a,b} = (A_a B_b - A_b B_a)(2y - j) = W_{a,b}(t) \cdot (y - c),$$
where $W_{a,b}(t) := A_a B_b - A_b B_a$ (a "discrete Wronskian" of the $A, B$ pair).

The denominator: $V = (u-y)(u-c)(y-c)$. Under $u = t, y+c = j, yc = t$:
$$(u-y)(u-c) = u^2 - u(y+c) + yc = t^2 - tj + t = t(t - (j-1)) = t(t - 2l).$$

Therefore
$$F_\mu(t) := s^*_\mu(u,y,c)\big|_{u=t,\ y+c=j,\ yc=t} = \frac{N_\mu(t)}{t(t-2l)},$$
$$N_\mu(t) = [t]_{k_1} W_{k_2, k_3} - [t]_{k_2} W_{k_1, k_3} + [t]_{k_3} W_{k_1, k_2}.$$

Both $F_\mu(t)$ and $N_\mu(t)$ are polynomials in $t$ (the divisibility of $N_\mu$ by $t(t-2l)$ follows since $F_\mu$ is a polynomial by the symmetric-function structure).

**We want $[t^{d_\mu}] F_\mu(t) = [t^{d_\mu+2}] N_\mu(t) = (-1)^m \delta_{m,l}$.**

---

## Lemma A (the key cancellation): $W_{k_2, k_3} = 0$

**Claim.** For our family, $W_{k_2, k_3}(t) = 0$ identically.

**Closed form for $W_{a,b}$.** Let $y_\pm = (j \pm \sqrt{j^2-4t})/2$. Then $A_a = ([y_+]_a - [y_-]_a)/(y_+ - y_-)$ (interpolation), and one checks (for $a > b$):
$$W_{a,b}(t) = \underbrace{\prod_{i=0}^{b-1}(t - r_i)}_{= [y_+]_b [y_-]_b} \cdot \tilde A_{a-b}(j-2b,\ t - bj + b^2),$$
where $r_i = i(j-i)$ and $\tilde A_n(j', t')$ denotes the "$A_n$" polynomial in the shifted system $z^2 - j'z + t' = 0$ (with $z = y - b$).

**Apply to $(a,b) = (k_2, k_3) = (l+2+m,\ l-m)$:**
- $a - b = 2m+2$.
- $j - 2b = 2l+1 - 2(l-m) = 2m+1$, so the shifted system has $j' = 2m+1$.

Thus $W_{k_2, k_3} = \prod_{i=0}^{l-m-1}(t - r_i) \cdot \tilde A_{2m+2}(2m+1,\ t')$.

**Sub-lemma.** For any odd $j' = 2m+1$: $A_{2m+2}(2m+1, t) \equiv 0$.

*Proof of sub-lemma.* When $j = 2m+1$, we have (via the reindexing $i \mapsto 2m+1-i$):
$$[c]_{2m+2} = \prod_{i=0}^{2m+1}(c - i) = \prod_{i=0}^{2m+1}((2m+1-i) - y) = \prod_{i'=0}^{2m+1}(i' - y) = [y]_{2m+2}$$
(the sign is $(-1)^{2m+2} = +1$). Therefore
$$A_{2m+2}\, y + B_{2m+2} = [y]_{2m+2} = [c]_{2m+2} = -A_{2m+2}\, y + (A_{2m+2}\,j + B_{2m+2}),$$
comparing $y$-coefficients: $A_{2m+2} = -A_{2m+2}$, so $A_{2m+2} = 0$. $\blacksquare$

Hence $W_{k_2, k_3}(t) = 0$, and
$$\boxed{N_\mu(t) = [t]_{k_3}\, W_{k_1, k_2} - [t]_{k_2}\, W_{k_1, k_3}.}$$

---

## Lemma B (degree bound): case $m < l$

**Claim.** For $m < l$: $\deg_t N_\mu \le d_\mu + 1 = 3l+2$. Hence $[t^{d_\mu+2}] N_\mu = 0$, i.e., $[t^{d_\mu}] F_\mu = 0$.

**Proof.** Using $\deg_t W_{a,b} = b + \lfloor(a-b-1)/2\rfloor$ (from the $[y_+][y_-]$-formula):

**Term 1** $[t]_{k_2} W_{k_1, k_3}$:
$$\deg = k_2 + k_3 + \lfloor(k_1 - k_3 - 1)/2\rfloor = (l+2+m) + (l-m) + \lfloor(l+m+2)/2\rfloor = 2l+2 + \lfloor(l+m+2)/2\rfloor.$$
For $m < l$: $l+m+2 < 2l+2$, so $\lfloor(l+m+2)/2\rfloor \le l$. Thus $\deg \le 3l+2$.

**Term 2** $[t]_{k_3} W_{k_1, k_2}$:
$$\deg = k_3 + k_2 + \lfloor(k_1-k_2-1)/2\rfloor = 2l+2 + \lfloor(l-m)/2\rfloor \le 2l+2 + l/2 < 3l+3.$$
So $\deg \le 3l+2$.

Both terms have degree $\le 3l+2 < d_\mu + 2 = 3l+3$. Therefore $\deg N_\mu \le 3l+2$ and $[t^{d_\mu+2}] N_\mu = 0$.

$$\boxed{\bar s^*_{\mu^{(m)}}(j) = 0 \text{ for } m < l.}$$

---

## Lemma C (leading coefficient): case $m = l$

**Claim.** For $m = l$: $[t^{d_\mu+2}] N_\mu = (-1)^l$.

**Proof.** At $m = l$: $k = (2l+3, 2l+2, 0)$, and $[t]_{k_3} = [t]_0 = 1$.

Also $A_{2l+2} = 0$ (Sub-lemma above, since $j' = j = 2l+1$ and $2m+2 = 2l+2$). Thus:
- $A_{2l+3} = (j-(2l+2)) A_{2l+2} + B_{2l+2} = -1 \cdot 0 + B_{2l+2} = B_{2l+2}$.
- $W_{2l+3, 0} = A_{2l+3} B_0 - A_0 B_{2l+3} = A_{2l+3} = B_{2l+2}$.
- $W_{2l+3, 2l+2} = A_{2l+3} B_{2l+2} - A_{2l+2} B_{2l+3} = B_{2l+2}^2 - 0 = B_{2l+2}^2$.

So $N_{\mu^{(l)}}(t) = B_{2l+2}^2 - [t]_{2l+2} \cdot B_{2l+2} = B_{2l+2}\left(B_{2l+2} - [t]_{2l+2}\right)$.

**Closed form for $B_{2l+2}$.** From the sub-lemma's identity $[y]_{2l+2} = [c]_{2l+2}$: the reduction is $y$-independent, so $[y]_{2l+2} \equiv B_{2l+2}(t)$. Moreover,
$$B_{2l+2}(t)^2 = [y]_{2l+2}[c]_{2l+2} = \prod_{i=0}^{2l+1}(y-i)(c-i) = \prod_{i=0}^{2l+1}(t - r_i) = \prod_{k=0}^{l}(t - r_k)^2$$
(pairing $i$ with $2l+1-i$ gives $r_i = r_{2l+1-i}$).

Hence $B_{2l+2}(t) = \varepsilon \prod_{k=0}^{l}(t - r_k)$ for some sign $\varepsilon \in \{\pm 1\}$. Comparing the leading $t^{l+1}$-coefficient: from the recursion, $B_{2n}$ has leading coefficient $(-1)^n$ (induction, using $B_{k+1} = -tA_k - kB_k$). So for $n = l+1$: leading coef $= (-1)^{l+1}$.

Therefore $B_{2l+2}(t) = (-1)^{l+1} \prod_{k=0}^{l}(t - r_k)$, with $\deg = l+1$, leading coef $(-1)^{l+1}$.

**Leading coef of $N_{\mu^{(l)}}$.** Since $\deg[t]_{2l+2} = 2l+2 > l+1 = \deg B_{2l+2}$, the leading of $B_{2l+2} - [t]_{2l+2}$ is $-t^{2l+2}$ (coef $-1$). Thus
$$[t^{3l+3}] N_{\mu^{(l)}} = [t^{l+1}] B_{2l+2} \cdot [t^{2l+2}](B_{2l+2} - [t]_{2l+2}) = (-1)^{l+1} \cdot (-1) = (-1)^l.$$

$$\boxed{\bar s^*_{\mu^{(l)}}(j) = (-1)^l.}$$

## Assembly

Combining Lemmas A, B, C:
$$\bar s^*_{\mu^{(m)}}(2l+1) = [t^{d_\mu}] F_\mu(t) = (-1)^m \delta_{m,l}. \qquad \blacksquare$$
