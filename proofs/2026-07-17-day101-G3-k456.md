## 3. G3 for k = 5 — trivial via the P̂_5 factorisation

**Setup.** By (S_5♠), write S_5 = T_1 − T_2 where:
```
    T_1 := 60·(a+2)(a+1)·(b+1)·b,
    T_2 := 16·m·(2m-1)·(4m-1)·[10(a+2)(b+1) − (2m-1)(4m-3)(4m+1)].
```

**v_2(T_2) = 4 + e exactly.** The bracket equals `even − odd = odd`, so
v_2(bracket) = 0. The prefactor `16·m·(2m-1)(4m-1)` has v_2 = 4 + e (since
2m−1, 4m−1 are both odd).

**v_2(T_1) analysis on shell (a + b even).** Note (a+2)(a+1) is the product
of two consecutive integers (so v_2 ≥ 1), and (b+1)·b is another such (v_2
≥ 1). Combined with v_2(60) = 2:
- Case E (a even, b even): a+2 even, a+1 odd, b even, b+1 odd. So
  v_2(T_1) = 2 + v_2(a+2) + v_2(b) = 2 + α + γ where α := v_2(a+2) ≥ 1,
  γ := v_2(b) ≥ 1 (assuming b ≥ 2; if b = 0 then T_1 = 0 and v_2(S_5) =
  v_2(T_2) = 4 + e).
- Case O (a odd, b odd): a+2 odd, a+1 even, b odd, b+1 even. So
  v_2(T_1) = 2 + v_2(a+1) + v_2(b+1) = 2 + α' + γ' with α', γ' ≥ 1.

In either shell case (a nondegenerate), v_2(T_1) = 2 + T where T ≥ 2 is
the sum of two exponents.

**Ultrametric case-split.**
- v_2(T_1) < v_2(T_2): v_2(S_5) = v_2(T_1) = 2 + T. Since T ≥ 2:
  v_2(S_5) ≥ 4. ✓
- v_2(T_1) > v_2(T_2): v_2(S_5) = 4 + e ≥ 4. ✓
- v_2(T_1) = v_2(T_2): v_2(S_5) ≥ 4 + e ≥ 4. ✓
- Degenerate T_1 = 0 (b = 0 in Case E): v_2(S_5) = v_2(T_2) = 4 + e ≥ 4. ✓

**In every subcase, v_2(S_5) ≥ 4.** Combined with carries ≥ 0 (trivial),
the reduced target `carries + v_2(S_5) ≥ 4` holds. ∎

**Corollary 3.1 (G3 for k = 5).** For c = 4m + 2, m ≥ 1, all shell (a, b):
`v_2(h_5^{(c)}(a, b)) ≥ β(c) − D_anchor(c)`. **PROVED unconditionally.**

## 5. G3 for k = 4 — case analysis with X-carries sublemma

Reduced target: `carries + v_2(S_4) ≥ 6 + e`.

**Setup by (S_4♠):** S_4 = T_1 − T_2 with:
```
    T_1 := 12·(a+1)(a+2)·b·(b+1),
    T_2 := 32·m²·(4m-1)·[6·(a+2)(b+1) + (2m-1)(4m-1)(4m+1)].
```

**v_2(T_2) = 5 + 2e exactly** (analogous to §3: bracket = even + odd = odd,
so v_2(bracket) = 0; prefactor v_2 = 5 + 2e).

**v_2(T_1) on shell:** Analogous to §3,
- Case E: v_2(T_1) = 2 + α + γ where α := v_2(a+2), γ := v_2(b),
  both ≥ 1 (assuming a, b ≥ 0 non-degenerate).
- Case O: v_2(T_1) = 2 + α' + γ' with α' := v_2(a+1), γ' := v_2(b+1),
  both ≥ 1.

Let T := α + γ (or α' + γ') denote the shell parameter. On the non-degenerate
shell, T ≥ 2. Degenerate corners (T_1 = 0) go into Case B below.

### 5.1 Case B (v_2(T_1) ≥ 5 + 2e)

Here v_2(S_4) ≥ 5 + 2e. Need: `carries ≥ 1 − e`.
- e ≥ 1: trivial (carries ≥ 0 ≥ 1 − e).
- e = 0: need carries ≥ 1. On shell (bit-0 chain, L = 4m − 3 has bit 0 = 1):
  - Case E: b+1 odd, carries_b ≥ 1. ✓
  - Case O: a+2 odd, carries_a ≥ 1. ✓
- Degenerate b = 0 (Case E): T_1 = 0, v_2(S_4) = v_2(T_2) = 5 + 2e, and
  carries_b(1, L) = carries((0+1), 4m−3) ≥ 1 (since 1 + L bit 0 chain
  gives at least one carry). ✓

### 5.2 Case A (v_2(T_1) < 5 + 2e)

Here v_2(S_4) = v_2(T_1) = 2 + T. Need: `carries + T ≥ 4 + e`.

Case A requires 2 + T < 5 + 2e, i.e., T ≤ 2 + 2e.

**The core sublemma.**

**Sublemma X-carries.** For X ≥ 1 and M ≥ 1 with ν := v_2(X), e := v_2(M):
```
    carries(X, 2M − 1) ≥ max(0, e − ν + 1).                              (X-C)
```

*Proof.* If ν > e, RHS = 0, trivial. Assume ν ≤ e. Structural facts:
- X: bit 0..(ν−1) = 0, bit ν = 1, higher bits arbitrary.
- 2M − 1: write M = 2^e·m' with m' odd, so 2M = 2^(e+1)·m' and
  2M − 1 = (2^(e+1) − 1) + 2^(e+1)·(m'−1). Since m'−1 is even, bits 0..e
  of 2M−1 all equal 1 (from the 2^(e+1)−1 term), bit e+1 = 0, and higher
  bits come from (m'−1)/2 shifted up by (e+2).

Bit-by-bit addition of X + (2M−1):
- Bits 0..(ν−1): X_i = 0, (2M−1)_i = 1 (i ≤ e). Sum = 1, no carry.
- Bit ν: X_ν = 1, (2M−1)_ν = 1 (ν ≤ e). Sum = 2 (+ any bit-0 carry). Carry
  out — count as carry #1.
- Bit i for i in (ν, e]: X_i ∈ {0, 1}, (2M−1)_i = 1, carry_in = 1.
  Sum = X_i + 1 + 1 = 2 + X_i ≥ 2. Carry out.

Carries counted from bit ν through bit e: 1 + (e − ν) = e − ν + 1. ∎

**Rewriting carries in terms of X-carries.** The following identities hold
via Kummer + the s_2 telescoping computed in `code/2026-07-17-day101-k456-verify.py`
and derived below:

**Sublemma L4 (carries formulas, L = 4m − 3).**
```
    carries_a(a+2, L) = 1 + carries((a+1)/2, 2m−1)      for a odd,
    carries_a(a+2, L) =     carries((a+2)/2, 2(m−1))    for a even,
    carries_b(b+1, L) = 1 + carries(b/2, 2m−1)          for b even,
    carries_b(b+1, L) =     carries((b+1)/2, 2(m−1))    for b odd.
```

*Proof (for the b-even formula; others analogous).* Write b = 2·b_1, so
b+1 = 2·b_1 + 1 has bit 0 = 1 and bits ≥ 1 mirroring b_1 shifted up by 1.
Hence s_2(b+1) = 1 + s_2(b_1). Similarly L = 4m − 3 = 4(m−1) + 1, so
s_2(L) = 1 + s_2(m−1). Sum: b+1+L = 2·b_1 + 4(m−1) + 2 = 2·(b_1 + 2(m−1) + 1)
= 2·(b_1 + 2m − 1). So s_2(b+1+L) = s_2(b_1 + 2m − 1).

Substituting into Kummer:
```
    carries_b = s_2(b+1) + s_2(L) − s_2(b+1+L)
              = 1 + s_2(b_1) + 1 + s_2(m−1) − s_2(b_1 + 2m − 1)
              = 2 + s_2(b_1) + s_2(m−1) − [s_2(b_1) + s_2(2m−1) − carries(b_1, 2m−1)]
              = 2 + s_2(m−1) − s_2(2m−1) + carries(b_1, 2m−1).
```
Since 2m−1 = 2(m−1) + 1 has bit 0 = 1 and bits ≥ 1 mirroring (m−1), we get
s_2(2m−1) = 1 + s_2(m−1). So `carries_b = 2 + (−1) + carries(b_1, 2m−1) =
1 + carries(b/2, 2m−1)`. ∎

The other three formulas follow similarly (see the verification script). ∎

Additionally:
- v_2(b/2) = v_2(b) − 1 = γ − 1 for b even.
- v_2((a+1)/2) = v_2(a+1) − 1 = α' − 1 for a odd.

### 5.3 Case A closure

**Case A-E (a even, b even ≥ 2).** T = α + γ, α ≥ 1, γ ≥ 1. Need
`carries + T ≥ 4 + e`.

Apply (X-C) with X = b/2, M = m, ν = γ − 1, e = v_2(m):
```
    carries(b/2, 2m − 1) ≥ max(0, e − (γ − 1) + 1) = max(0, e − γ + 2).
```
Hence `carries_b(b+1, L) = 1 + carries(b/2, 2m − 1) ≥ 1 + max(0, e − γ + 2)`.

Two sub-subcases:
- **γ ≤ e + 2**: carries_b ≥ e − γ + 3. Then
  carries + T ≥ 0 + (e − γ + 3) + (α + γ) = e + 3 + α ≥ e + 4
  (since α ≥ 1). ✓
- **γ ≥ e + 3**: carries_b ≥ 1. Then
  carries + T ≥ 0 + 1 + α + γ ≥ 1 + 1 + (e + 3) = e + 5 ≥ e + 4. ✓

**Case A-O (a odd, b odd).** T = α' + γ', α', γ' ≥ 1. Symmetric: apply
(X-C) with X = (a+1)/2, M = m, ν = α' − 1:
```
    carries_a(a+2, L) = 1 + carries((a+1)/2, 2m − 1) ≥ 1 + max(0, e − α' + 2).
```
The same two-subcase analysis yields:
- α' ≤ e + 2: carries + T ≥ (e − α' + 3) + α' + γ' = e + 3 + γ' ≥ e + 4. ✓
- α' ≥ e + 3: carries + T ≥ 1 + α' + γ' ≥ 2 + (e + 3) = e + 5. ✓

### 5.4 k = 4 conclusion

**Corollary 5.1 (G3 for k = 4).** For c = 4m + 2, m ≥ 1, all shell (a, b):
`v_2(h_4^{(c)}(a, b)) ≥ β(c) − D_anchor(c)`. **PROVED unconditionally.** ∎

### §11. UNIFORM STRENGTHENING (Day 101 bonus): Lemmas UB7 and UB8

The trivial factor `−8` (k=7) and `16` (k=8) give v_2(S_k) ≥ 3 or 4. But
the pattern in §5's k=4 case suggested looking at higher divisibilities.
Direct mod-N computation reveals a much stronger structure:

**Lemma UB7 (uniform bound on P̂_7).** For all integers (a, b, m):
```
    P̂_7(a, b, m) ≡ 0 (mod 4),   equivalently   v_2(P̂_7) ≥ 2.
```
Hence `v_2(S_7(a, b, 4m+2)) ≥ 3 + 2 = 5` unconditionally.

*Proof.* Since P̂_7 is a polynomial with integer coefficients, its value
mod 4 depends only on `(a mod 4, b mod 4, m mod 4)`. Direct evaluation on
`(Z/4Z)^3 = 64` residue configurations gives 0 in every case. See
`code/2026-07-17-day101-uniform-bounds-verify.py`. ∎

**Lemma UB8 (uniform bound on P̂_8).** For all integers (a, b, m):
```
    P̂_8(a, b, m) ≡ 0 (mod 32),   equivalently   v_2(P̂_8) ≥ 5.
```
Hence `v_2(S_8(a, b, 4m+2)) ≥ 4 + 5 = 9` unconditionally.

*Proof.* Same principle — evaluate P̂_8 mod 32 on `(Z/32Z)^3 = 32,768`
residue configurations. Every value is 0 mod 32. Verified in the same
script. ∎

**Remark.** These are novel divisibility identities, not follow-ons from
Day 100 CODE — the CODE only extracted the `−8` and `16` factors as
Q_k-catalog cleanups. UB7 and UB8 emerge from evaluating P̂_k at low
residues and observing the mod-4 / mod-32 zero pattern. The fact that
UB8 gives an extra 2^5 = 32 (vs. the mere 2^2 = 4 for UB7) is
consistent with the k=8 case admitting more shell parity structure —
specifically, P̂_8 has degree 4 in each of (a, b) whereas P̂_7 has degree
3, and the extra degree buys additional 2-adic mass.

### §11.1 Reduction of G3-k=7 to a clean sublemma

Combining UB7 with the reduction from §1:
```
    v_2(h_7^{(4m+2)}(a, b)) = 2·v_2(L!) + carries_a + carries_b + v_2(Q_7)
                            ≥ 2·v_2(L!) + carries + (4 + e) + 5
                            = 2·v_2(L!) + carries + 9 + e.
```
where L = 4m − 6 and carries = carries_a(a+2, L) + carries_b(b+1, L).

Target β − D_anchor = 8m + 1 − 2·s_2(m) − v_2(m). Substituting
`2·v_2(L!) = 2·(4m − 6 − s_2(4m−6))`, and using s_2(4m−6) = s_2(2m−3)
(since 4m−6 = 2·(2m−3)) plus the identity `s_2(2m−3) = v_2(m−1) + s_2(m−1)`
(derived at m ≥ 2 from the borrow chain of subtracting 1 from 2(m−1)),
plus Legendre `s_2(m) − s_2(m−1) = 1 − v_2(m)`, the reduction becomes:

**Sublemma G3-k=7-REDUCED.** For c = 4m + 2, m ≥ 2, all shell (a, b):
```
    carries_a(a+2, 4m−6) + carries_b(b+1, 4m−6) + v_2(P̂_7(a, b, m))
        ≥ 2·v_2(m − 1) + 2 + 2.
```
(The last `+2` on the RHS is subsumed by v_2(P̂_7) ≥ 2 [UB7]; equivalently:
`carries + (v_2(P̂_7) − 2) ≥ 2·v_2(m − 1) + 2`.)

**Status.** Verified numerically over 30,400 shell configurations
(m ∈ [1, 40], (a, b) ∈ [0, 40)²), 0 violations. The tight boundary is
achieved along the anchor family `(0, 2j)`, j ≥ 1, where `v_2(P̂_7) = 2`
exactly and `carries = 2 + 2·v_2(m−1)` exactly.

**Analytic status: SKETCHED.** The X-carries sublemma of §5.2 gives
`carries(X, 2M−1) ≥ max(0, v_2(M) − v_2(X) + 1)` where here
M = m − 1. Applied to X_a = ⌊(a+2)/2⌋ and X_b = ⌊(b+1)/2⌋ (using
`carries(x, 2y) = carries(⌊x/2⌋, y)` for the L = 2·(2M−1) reduction),
the two bounds sum to `≥ 2 + 2·v_2(m−1) − v_2(X_a) − v_2(X_b)`. So we
need an ADDITIONAL analytic bound `v_2(P̂_7) − 2 ≥ v_2(X_a) + v_2(X_b)`
in the case v_2(X_a), v_2(X_b) ≤ v_2(m−1). Numerical scan
(`k7-joint-bound.py`) shows this holds when max(v_2(X_a), v_2(X_b)) ≤
v_2(m − 1), but has counterexamples when the coordinate exceeds v_2(m−1)
— those cases are handled by X-carries returning 0 with v_2(P̂_7)
picking up slack. A tighter joint bound `v_2(P̂_7) − 2 + carries ≥
2 + 2·v_2(m − 1)` holds empirically but requires a case analysis mod-2^N
in shell parity × m-parity that we defer.
