## 1. Definitions (from `2026-11-08-q68-typeA-closure.md` §1, §4 and `2026-11-09-q69-typeD-C3.md`)

- **Left cell Γ.** Left preorder: y ≤_L w is generated by "μ̃(y,w) ≠ 0 and L(y) ⊄ L(w)". L varies inside Γ and R is constant on Γ.
- **Dominated twin.** x ≠ z ∈ Γ with L(z) ⊆ L(x) and
  (TW) μ̃(y,z) ≥ μ̃(y,x) for every y ∈ Γ with L(y) ⊄ L(x).
  A twin makes C_KL(Γ) non-maximal (Lemma A).
- **(★).** Γ has no *candidate pair*, i.e. no x ≠ z ∈ Γ with ∅ ≠ L(z) ⊆ int L(x).
  - By C2 (simply laced), twin ⇒ candidate pair.
  - By Prop C3, proved for any W, (★) depends only on [Γ].
- **Theorem W (witness completeness).** It is **proved for every finite Coxeter group**. Its inputs are (F1), μ ≥ 0 and (K5), so it transfers to D_n verbatim.
  - (x,z) is a twin ⟺ μ̃(y,z) ≥ μ̃(y,x) for all y ∈ W_i(x) ∪ W_ii(x).
  - W_i(x) = {sx ∈ Γ : L(sx) ⊄ L(x)}. Here μ̃(sx,x) = 1, so the condition reads μ̃(sx,z) ≥ 1.
  - W_ii(x) = {y ∈ Γ : L(y) ⊋ L(x), y < x}.
- **What does NOT transfer: Prop Q (cell independence).** It is proved via Knuth's theorem and RSK: all left cells of one shape are joined by right stars.
  - In D_n the right-star half still holds for any W with m = 3. Right stars map left cells to left cells and preserve L and μ̃ (Lemma S, right version). So a verdict is constant on a right-star class of cells.
  - It is **not known** that all cells with the same constructible character form one right-star class. Garfinkle's type-D theory needs extra "moving through cycles" moves.
  - Hence each of the 2016 D8 cells is a separate instance unless a type-D Prop Q is proved or the classes are computed.
  - Also, Prop C3 makes (★) a function of [Γ], but twin-ness is not known to be.

**(c) D8 cells are not star or F2 orbits.**
- `f2_closure` is the closure under u ↦ ru with L(u), L(ru) incomparable. By (F1)+(F2) this is exactly the set of μ-links with incomparable descents, so the closure lies inside the cell, and it needs no KL.
- In D8 the closure sizes are {14, 20, 21, 28, 35, 42, 56, 64, 70, 84, 98, 112, 126, 140, 154, 210, 224, 252, 280, 315, 336, 420, 448, 560, 630, 840, 1260}. No closure has size 616, 700, 728 or 980. Left-star orbits give the same sizes (`find_rep.py`, `find_rep2.py`).
- So every violator cell is a union of several F2-pieces, glued by **non-local** μ-edges. By (F1) such an edge has y < u, L(y) ⊋ L(u) and gap ≥ 3.
- Example, type [1.331]+[2.321]:
  - A 280-piece P1 has R = {2,3,5,8} (`glue2.py`, seed 3).
  - It is missing 336 elements. Among all 36930 elements with the same R and L in the missing support, the sub-distribution pieces are 19×42 and 5×126.
  - **1710** subsets (e.g. 42+42+126+126) reproduce the missing distribution exactly.
  - So descent statistics alone cannot assemble the cell. Gluing needs μ.

**(d) Gluing cost probe** (`edge_probe.py`).
- Between P1 and those 24 pieces there are 12215 non-local candidate pairs (length/descent prefilter).
- On 40 random ones, the persistent coxeter3 session ran at **0.74 s per `pol` call**. 18 pairs were not Bruhat-comparable and **2 had μ ≠ 0**. So non-local glue edges exist and are hit at about 5%.
- The persistent session is `d8lib.Cox`: it uses stdbuf, keeps its context, and is roughly 8× faster than one process per pair.

## 4. Plan (one representative cell per type)

1. **Pieces (no KL, seconds).** Pick x with L(x) the candidate set. Compute the F2-piece of x. Enumerate all u with R(u) = R(x), which takes about 15 s in Python, and split them into F2-pieces.
2. **Glue (KL).** Build the piece digraph.
   - Local arcs are free: u → ru with comparable descents.
   - Non-local arcs y ≤_L u come from `pol` on pairs (y < u, L(y) ⊋ L(u), odd gap). Stop at the first μ ≠ 0 per ordered piece pair.
   - The cell is the strongly connected component of P(x).
   - **Stopping rule.** Stop when the component reaches dim and its distribution equals the target. Then Γ ⊇ component and |Γ| = dim[Γ]. This gives Γ = component, provided no constructible distribution strictly dominates the target (a check to add; done from `targets`/`Con`).
   - Only positive edges are needed, so the expected cost is tens of calls per glued piece. Worst case is 12k calls ≈ 2.5 h per P1-row.
3. **Decide (Theorem W).** For each candidate pair (x,z), at most 4 per shape:
   - W_i(x): ≤ 8 elements. One `pol` call each for μ̃(sx,z). Membership in Γ is free when L(x) ⊄ L(sx) (F2); otherwise read it from Γ.
   - W_ii(x): the y ∈ Γ with L(y) ⊋ L(x) and l(y) < l(x). One `pol` call each for μ(y,x), and then for μ̃(y,z) where μ(y,x) ≠ 0.
   - Prefilter by parity (Cor W2): l(x) ≡ l(z).
   - Estimate: ≤ about 200 calls per pair, under 3 min.
4. **Per type:** about 5–30 min, so **all 8 representatives take about 1–4 h** at 0.74 s per call on 1 core. The 4 cores allow 4 parallel sessions.
5. **Full decision** (all 2016 cells) needs either:
   - a type-D Prop Q (right-star transport between cells of equal character), proved, or
   - a computed partition of the 2016 cells into right-star classes. Right stars act on pieces combinatorially, with no KL. Then one representative per class.

   If the classes are not the 8 types, cost scales with the number of classes.

**Caveat.** A TWIN verdict in step 3 needs Γ exactly. A NO verdict needs only the killing y certified in Γ. W_i elements with L(x) ⊄ L(sx) are in Γ by F2, with no gluing. So a cheap first pass is "W_i-kills only", which can return NO with no gluing at all.
